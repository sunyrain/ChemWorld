# ChemWorld 实验观测台

本地只读展示平台：统一浏览当前证据报告和本地实验批次，查看条件指标、逐步观测与资源，
重放已有实验文件。无需安装前端依赖，不连接模型服务，不上传实验数据。

在仓库根目录启动：

```powershell
uv run --no-sync python -m apps.experiment_explorer
```

打开 **http://127.0.0.1:8890**。服务只监听本机；终端内按 `Ctrl+C` 停止。

额外挂载本机其他实验目录，或更换端口：

```powershell
uv run --no-sync python -m apps.experiment_explorer --port 8891 --runs D:/Experiments/Archive
```

`--runs` 可重复使用，始终保留仓库的 `runs/`。新文件写入后点击“刷新目录”。

## 浏览实验

- **当前绑定报告**：递归解析 `configs/current.json` 中绑定到 `workstreams/**/reports/*.json`
  的路径及绑定到 `runs/` 的 summary/report/results，按路径去重。不会根据文件名中的版本号
  挑选报告，也不会把 producer 命令当成路径。本地批次中未绑定的常规 summary/report/results
  文件仅在该批次详情中显示，多文件分别呈现。
- **本地实验批次**：扫描 `runs/` 及指定归档目录。标准轨迹索引路径、时间和任务类别；旧格式的
  自定义 JSONL 文件名通过首条 action 记录识别。跳过 provider/raw 目录及已知服务日志。
  索引包含失败、空文件及中断轨迹，空/损坏文件在打开时显示错误。
- 左侧按电化学、反应与热过程、萃取与纯化、结晶、蒸馏、相与平衡及表征、连续流分类。
  类别取自报告、路径或首条轨迹中的实际任务标识；无法识别的条目进入“综合与未分类”。
  跨类别档案可出现在多个类别中，数字为档案数而非独立实验数。来源与证据身份作为次级筛选。
  手动导入的文件在首次打开解析后按记录内容归类。
- 报告显示原始计数与分母、条件表及可切换指标图；表格分页，图中明确标注最多显示前80条。
  CSV 导出包含选定表的全部行，原始记录可按需展开所有字段。
- 通过报告显式记录的运行目录、source directory 或 JSONL 路径关联轨迹；找不到关联的
  报告不会猜测目录。完整的本地批次目录仍可单独搜索。

“当前绑定”描述证据来源，不表示当前运行时重新取得资格。`formal` 文件夹不自动证明正式身份；
没有明确声明的记录标注“未声明”。报告、批次和轨迹分别计数，不能相加当作独立实验数。
不同协议之间不合并成功率；未观测值保留缺失，质量不通过、事务失败、服务中断分别保留。
同一轨迹可能被多个报告引用，索引的轨迹文件总数只按路径计一次。

## 本地文件回放

选择“实验组与回放”，或拖入/选择一个或多个文件：

- `.jsonl`：每行一条带 `action` 对象的 ChemWorld 轨迹记录。
- `.json`：轨迹数组、包含 `records` / `trajectory` 数组的对象，或普通实验报告。

手动导入仅在浏览器内存中读取，刷新网页后需重新导入，不会上传或保存副本。
每个文件的显示上限为128 MiB；大归档通过目录索引分页选择。

支持播放/暂停、0.5×/1×/2×/4×、上一步/下一步、回到起点、时间轴拖动和点击曲线跳转。
焦点不在输入或按钮时，可使用空格及左右方向键。切换实验、视图或隐藏页面会暂停播放。

- **整组实验**：原始轨迹中连续开展的多轮实验，按实验索引、会话变更和成功终检边界分段。
  显示每轮卡片、终检指标曲线、参数序列差异、操作覆盖热图及已保存的模型交付。
  小实验数量以记录为准，不固定为8–12次；终检完成也不等于质量达标。
- **单次实验**：操作流程与三栏 IO，分别呈现操作前输入、模型输出/决策说明、工具反馈。
  原文件有完整请求时直接展示；只有决策上下文时明确标注其范围。未保存的提示词和解释
  不进行重建，不把事后观测当作事前输入。可展开原字段或导出本步 IO。
- **一次规划、分文件执行**：对已有 `physical/source/<source>/<round>/<member>` 布局，
  只在相应规划结果的 payload 明确包含该 member 时标记关联。每个矩阵/方案保持独立，
  不将8个文件拼成连续实验组。显示控制器类型、原方案标识与该方案的模型规划输出；
  脚本执行步骤不冒充逐步模型决策。

回放按记录顺序每步展示一秒，速度控制只改变展示时间；真实过程秒数取自资源账本。
每次跳转重新读取该步快照，不重新执行动作，不把未来读数或未观测字段填入当前状态。
原记录中的沿用测量保持沿用，不推断为新测量；物理费用与归一化 observation cost 区分显示。
单纯 terminate 不代表完成终检或质量合格。JSONL 损坏时只保留首个损坏行之前的连续前缀，
展示行号及错误，不跳过损坏动作伪造完整过程。

**精确重算验证**仅对目录中的原始轨迹开放：调用现有 `verify_records(tolerance=0)`，
在内存中从记录合同重演，显示检查步数、最大误差及全部失配。服务同时只运行一个验证任务。
播放和验证是两个独立动作。验证结果仅属于当前本地运行时，不写回原报告，不覆盖历史资格；
旧版本语义或缺失私有干预导致失败时如实报告。手动导入文件若要验证，先将原文件放进
已配置实验目录再刷新。平台不会读取任意浏览器传入的磁盘路径。

## 实现与验证

沿用仓库应用的 Python 标准库 HTTP 服务与原生浏览器模块，无新运行依赖。
服务只开放索引内文件与固定静态资源，校验本机 Host/Origin；动态文本以文本节点渲染。
实验文件、凭据、日志、测试临时目录及原始 provider payload 不进入 Git。

```powershell
uv run --no-sync pytest tests/test_experiment_explorer.py -q
uv run --no-sync ruff check apps/experiment_explorer tests/test_experiment_explorer.py
node --test apps/experiment_explorer/test_replay.mjs
node --check apps/experiment_explorer/static/app.mjs
node --check apps/experiment_explorer/static/viewer.mjs
```

2026-09-16本机验收：86份去重绑定报告、260个本地批次、49,587个轨迹文件，索引错误0。
完整流程总报告关联145条轨迹；一条20步现存轨迹通过当前版本零误差重算。
20项Python测试和15项回放逻辑测试通过，覆盖类别、独立方案关联、实验边界与每步 IO 对齐。
另以实际HTTP数据完成DOM交互检查；该检查为DOM模拟，不代替真实浏览器的视觉验收。
这些是展示平台功能验收，不产生新科学实验结果，也不改变冻结证据。

现有3D实验室保持独立，可参见 [Blender laboratory](../blender_lab/README.md)。
