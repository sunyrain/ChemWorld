# Agent 自主探索 · 双主题定稿

用户已将五版探索收敛为同一布局的浅色与深色模式。使用内置 image_gen 生成浅色稿，再以浅色稿定向生成深色稿，保持布局和功能一致。

[双主题预览](index.html) · [浅色原图](light.png) · [深色原图](dark.png) · [提示词](prompts.json)

主流程是 Agent 自主选择操作、观测、写研究笔记并继续探索。人配置研究目标、模型和预算后观看结果；手动实验是独立可选入口，不设计人机共同编辑。ChemWorld 是虚拟实验室，不设置文献检索和资源库。

复现以左侧导航、大幅网络画布、右侧环境观测/Agent 笔记、底部执行事件为骨架。两种主题用同一 DOM 与语义色变量，切换只影响显示，记住用户选择。

图中数值与状态是概念数据。实现需从服务端事实生成：有组件网络时显示实际容器和连接；普通世界显示已提交动作构成的执行轨迹，明确连线是提交顺序，不能伪造为物料管路。谱图使用实际观测，笔记使用模型主动提交的版本。离线固定配方不称为自主 Agent。

当前运行器是单批实验，暂不支持暂停后恢复、Agent 自主新建跨批研究树或生成下一实验草稿；初版呈现实际停止能力，不设置假按钮或虚构未来计划。双主题和呈现重构不改变物理、计费、失败保留与精确回放语义。
