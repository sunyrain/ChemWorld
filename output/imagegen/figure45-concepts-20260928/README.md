All designs use English labels, dark anchoring text, white backgrounds and the
existing slate/teal/ochre information-arm palette. No overall figure title is
printed inside the images. Different layouts redistribute the same scientific
content; they are not additional analyses.

These are visual concepts, not publication evidence. Generated point positions,
axis spacing, intervals and numerical labels can differ from retained data.
