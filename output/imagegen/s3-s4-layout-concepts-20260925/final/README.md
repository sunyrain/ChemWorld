# S3 and S4 layout concepts

Eight ImageGen layout studies for selection only. The marks, amplitudes, colours,
mean slots and agent thought placeholders are illustrative; none is a plotted
scientific result. The manuscript figures were not replaced.

| File | Layout question |
| --- | --- |
| `S3-01-six-panel-grid.png` | Can six readouts each have enough space in a 2 × 3 grid? |
| `S3-02-graphical-table.png` | Can the complete world × arm lookup become a readable graphical table? |
| `S3-03-horizontal-bands.png` | Can six full-width bands pair a budget summary with a 5 × 3 matrix? |
| `S3-04-raincloud-strips.png` | Can six distribution strips foreground heterogeneity? Pair identity would need a companion table. |
| `S4-01-chronological-storyboard.png` | Can the full source → Q → K2 → reference order read vertically? |
| `S4-02-parallel-swimlanes.png` | Can two independent sessions read as parallel temporal lanes? |
| `S4-03-evidence-triptych.png` | Can the thermal contrast, two forecasts and reflection read side by side? |
| `S4-04-figure2-ledger.png` | Can S4 echo main Figure 2's experimental process and evidence-to-decision ledger? |

Shared final ImageGen prompt specification: English scientific figure format concept;
opaque white ground; black sans-serif text; restrained teal, muted blue and rust;
fine grey rules; no decorative chemistry art or heavy AI styling; sparse factual
labels; clearly marked `LAYOUT CONCEPT`. S3 variants were separately prompted as
2 × 3 small multiples, graphical table, six horizontal bands and six raincloud
strips. S4 variants were separately prompted as vertical chronology, parallel
swimlanes, thermal/forecast/reflection triptych and Figure-2-like process ledger.
The final images were flattened onto white because ImageGen returned transparent
backgrounds for some variants; their compositions were otherwise preserved.
