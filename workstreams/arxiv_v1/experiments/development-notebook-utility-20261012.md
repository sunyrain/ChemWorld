# R51：修复验收与记录本用途的连续研究试用

## 执行前固定设计（2026-10-12）

问题：假设记录本能否帮助人理解与审查 Agent 自主研究？它相对已有 history 和最终报告提供什么，跨会话是否实际被利用？这是开发试用，不是正式能力比较；不扩模型/世界矩阵，不修改既有失败。

先做一次 R50 修复后的真实 CLI 六调用检查：status → 全九项 schema → 写入 `连接诊断 — no physical experiment.` → 读回 → status → finish_batch 携带最终笔记。120 s、12 请求、0 物理动作，使用原模型和六步判据。全部完成、文本一致、无宿主/传输错误、usage 完整才通过。新结果单独保存，旧 4/6 failed 不变；不为模型误判或不服从反复重跑。若发现具体平台故障，保留失败，定向修复和测试后在本文另记新验证块。

随后固定 H/N 两条各 4 批自主研究，共 8 批。H 能按需读自己的完整事实 history、公共工件与历次已提交最终报告；N 同样拥有这些资料，另外为人类维护版本化假设记录本。两条均从空白开始，不把另一条研究者的轨迹给它读。相同问题：研究可控条件与产率/选择性的关系并检验其适用范围；配方、对照、重复和测量均由 Agent 选择。两条件都要求首次操作理由给出问题/可检验预期，关键行动给出公开科学理由，最终报告保留解释/证据/局限及后续决定；N 另要求将这些科学承诺维护在简洁笔记中，不强制读笔记、不自动注入正文、不因漏写锁实验。比较的是这套记录工作流，不是单独的读取动作或存储容量。

使用同一 reaction/thermal/observation 组合、world seed 0，批次独立初态与资源账；H/N 的第 k 批 observation seed 均为 4000+k，但不同测量选择可能消耗不同噪声位置，不宣称每个读数逐一配对。每批全新 gpt-5.6-sol / medium 原生 CLI/MCP 会话，禁用子 Agent、shell、外部工具。不更换模型。固定串行顺序 H1,N1,N2,H2,H3,N3,N4,H4；这只有每条件一条自适应研究轨迹，4 批不是 4 次独立重复。显式会话重置不是自然压缩，也不是一个连续上下文的长程证明。

预算：每批 24 次物理尝试（包括拒绝）、36 工具请求、300 s；每条研究线累计最多 1200 s、2000000 input+output tokens（含 cached，逐会话边界检查，最后一个已启动会话可能超过 token 软阈值）。报告/笔记/历史读写均占同一请求预算，不额外给 N 实验预算。每 20 s 输出当前条件/批次、完成/8、请求/物理动作数、吞吐与 ETA。超过配额不启动该条件后续批次，不挪配额。

失败和恢复：模型错误、拒绝、漏记、提前停止、不改善均作为结果保留，不补跑；若 usage 完整且事实记录/回放有效，继续该条件下一预定独立批次。宿主/传输/usage/回放故障停止受影响研究线；独立且没有共享平台故障的另一线可以继续。发现共享平台缺陷立即停止后续启动，保留已完成数据。平台修复改变公开接口或执行语义后，受影响研究线的新验证须从第一批开始、写明新块，不拼接新旧为完整轨迹；不自动恢复半途物理状态、不重做已提交动作。本块不新增救援条件或为有利结果重复。

预定读出：

1. 工程：8/8 终检及 finish_batch；所有非空轨迹零容差回放；逐步载体/测量资源检查；全部错误、失败、未执行槽位及完整用量。笔记遗漏与环境故障分别计数。
2. 可审查性：8 个槽位逐项审阅事前问题/预期、结果关联解释、后续决定及理由、适用范围/混杂。以清楚/部分/缺失/未执行和实际引用报告，不合成分数。H 也检查逐操作理由、最终报告和 CLI 公开消息，不将“没有笔记”等同于“没有解释”。N 同时检查笔记相对这些既有资料究竟增加了什么，是否有遗漏/错误/过时记录。不是盲法人类速度测量，不宣称减少多少审稿时间。
3. 连续性：各 3 个跨会话转换，实际检索资料及发生时点、是否正确区分计划/已执行、是否延续/有理由地调整上一批计划；不把机械遵循旧计划当成唯一成功。
4. 研究：保留实际条件与全部公开测量；核对前瞻预期与证据修订，按不确定性与采样差异解释。最高产率/文字量/检索次数均不作为笔记有效性单指标。只有一条轨迹/条件，不做显著性推断或因果能力提升声明。

产物：复用现有宿主/汇总逻辑，新增有界开发 runner；补充最终报告按需读取，明确其是模型陈述、不是权威事实，不混入 history。仓库外 `D:/Projects/ChemWorld-local-research/20261012-notebook-utility/` 保存 canary、study-attempt-01 的原始 IO、轨迹、笔记版本、完整机器摘要与阅览本。仓库中保留本文结果/人工审阅和脱敏机器聚合摘要。首次启动前完成定向测试。没有发布冻结、全仓审计或论文改写。
