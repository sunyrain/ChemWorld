# R53：长程研究中的同期记录校准

## 执行前设计（2026-10-12）

问题：在不额外要求逐步理由的连续自主研究中，增加假设笔记职责会留下哪些原本缺失的同期科学说明，是否能与后续行为对照，负担与遗漏是什么？供用户对比和校准记录方式；不是笔记提高能力的正式检验。R51/R52 是“明确要求同期理由”与“同期理由＋笔记”的试用，不能充当旧流程对照。

固定两条研究线 B（无专用笔记）/ N（增加假设笔记职责），每条 8 个独立初态的物理批次，共 16 槽位。用户已选择两条各一个持续 CLI 会话，不人工逐批清空上下文；可发生提供方自行压缩，保留实际事件，不宣称证明无限上下文能力。

两组共用同一科学任务：研究可控条件与最终产率/选择性的关系及其适用范围，自选变量、配方、测量、对照、重复和下一批。均保留普通终态研究报告；不要求事前预测、逐步理由、阶段反思或逐批解释报告，物理工具仅收 action。自然产生的公开说明照常保留，不禁止 B 自发解释。N 额外维护简短的可修订假设记录：初始问题/预期，重要证据后的修订或保留，适用边界及后续决定；自由组织格式，不抄 history、不按字数打分、不因漏写锁实验、不强制读取或自动注入正文。两组终报告的要求相同。

B 是当前环境下的无额外记录要求基线，**不是旧论文的逐字或逐环境复现**：本块使用当前组合世界、工具与资源。保留旧研究的连续操作取证形式；不混入历史的 decision_audit / belief_snapshot 要求。该差异在分析中显式保留。

环境与模型固定：reaction/thermal/observation 组合、world seed 0；第 k 批 observation seed 为 5000+k，双方相同但测量选择不同可能消耗不同噪声位置。gpt-5.6-sol / medium，单 actor，禁用子 Agent、shell、外部工具；顺序 B 后 N。每条只有一次自适应研究，8 批不是 8 次独立处理重复，顺序/随机性/证据选择不能从笔记作用中分离。旧结果和旧笔记不提供给新研究者。

预算：每条最多 30 分钟、288 次工具请求，每批最多 24 次环境操作尝试（含环境拒绝）；错误接口请求也计入工具预算。所有读写占共同请求预算，不给 N 额外实验预算。只在终检后由研究者请求新批次，不自动收尾。Token 用量含缓存按提供方终态报告；单次 CLI 会话内无法据完整 usage 实时限额，故不宣称有实时 token 硬限。遇时间/请求上限保留当前状态并终止，不提高预算、不补跑。每 20 秒输出组别、完成/16、当前批/步/请求数、吞吐和 ETA。

读出与验收：

1. 工程：16 槽位逐一报告执行/未执行、终检、失败；所有非空轨迹精确回放，守恒/测量时间/费用/采样扣量检查；保存完整 IO、最终报告、所有版本、公开消息和用量。没有笔记或解释不算工程失败。
2. 人类审查：逐批检查问题/预期、证据关联判断、修订/保留、后续实际行动及结论边界，区分同期明说、仅事后明说、行动可见但理由未记录。引用源与时点，不从行为代写原 Agent 假设；不把笔记陈述当内部思维或已验证机制。
3. 增量与负担：笔记写/读/版本数、字数、检索与工具成本、实际资源消耗；重复、遗漏、过时说法和计划未执行均保留。计数不代替质量，不以产率最高或写得最多判定笔记有效。

失败规则：模型错误、漏记、提前结束或不改善原样报告，不救援。宿主异常、守恒/重放缺陷等共享平台故障停止整个块；提供方/传输失败停止受影响研究线，不重启该会话，另一线仅在未发现共享平台缺陷时继续。平台修复后若要再验证，另立整个新块，从第一批开始，不拼接旧结果。

输出在仓库外 `D:/Projects/ChemWorld-local-research/20261012-notebook-calibration/study-attempt-01/`：每组完整记录、带来源的阅览 Markdown、两组对照页、机器 summary/aggregate。仓库只保留代码、测试、本说明及无原始 provider 正文的派生摘要。完成后在本节下追加实际结果；不新增实验条件或修改论文。
