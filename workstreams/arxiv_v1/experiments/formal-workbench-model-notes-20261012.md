# R63：自主模型实验与版本笔记的限定正式验收

## 执行前固定设计

用户于 2026-10-12 明确要求正式实验并包含模型笔记。本块是当前工作台数据路径的三案例正式验收，不是论文历史证据复现、多模型排名或笔记效果的因果实验。不改原论文与 Work II。

固定顺序：reaction-to-assay、reaction-to-crystallization、flow-reaction-optimization，各一个独立模型会话、一个物理批次，seed 7、操作预算 24。模型沿用既有已登录原生入口 gpt-5.6-sol / medium，无 shell、联网检索或子 Agent。只提供公共任务、状态、schema、历史、测量与笔记工具，不提供参考配方、旧实验结果或隐藏状态。三组各自的科学问题为反应产率/选择性、结晶回收/纯度、流动转化/选择性；具体条件和测量由模型决定。

明确要求模型在物理实验前写简短可检验预期，在重要证据后修订，在终检后写结论、证据和局限并提交报告。笔记格式自选、正文按需读取，不强制逐步理由或读取次数，不请求内部思维。漏写不锁定实验，也不由宿主补写。终检关闭物理环境后仍允许模型读取已保存证据和写报告。

每组最多 40 次工具请求（错误及笔记读写同计）、420 s；块最多 1260 s，组间累计 input+output tokens 达到 1500000 后不启动下一组。原生单会话完整 token 用量只在会话结束可得，该数是组间停止阈值而非实时硬上限。缓存 tokens 已含在 input 中，不重复相加；订阅费用不可归因则 USD 记 null。每 20 s 输出组/3、工具/40、操作/24、耗时、吞吐和可用 ETA。

执行前完成工具宿主定向测试并提交稳定代码；source commit、锁定环境及执行文件摘要记录在仓库外的 source-binding.json，一次绑定，不重建全局 readiness 或旧审计。原生提供方由既有 adapter 校验登录，不读取或复制临时 API key。本块不验收网页 BYOK。

固定读出与判定：

- 三个槽位逐一报告已执行、未启动、终检、截断、拒绝、回滚、宿主/提供方失败；所有非空轨迹零容差精确回放。
- 工程通过：三组终检、精确回放、完整提供方用量、无宿主/传输/平台失败。模型合法动作拒绝单列保留，不自动视为平台缺陷。
- 笔记通过：每组存在操作前及终检后的模型版本和最终报告；人工核对原文、事件引用时点、已测/未测边界。读取次数只报告，不作为通过条件。笔记不自动成为事实。
- 保存资源状态、全工具 IO、原始公开测量、全部版本与报告；模型工具请求数与不可观测的底层模型请求数分开。没有终检的指标为缺测，不填零。

停止规则：不自动重试、不替换不利结果。提供方/传输失败停止该组；宿主异常、constitution 回滚或精确回放失败停止整个块，剩余槽位明确未启动。已有 R62 的 240 s 加热回滚仍是已知待定位限制；不刻意指定回避该条件，也不把旧结果喂给模型。若本块遇到平台缺陷，保留失败，修复后的正式验收必须另从三组第一组开始，不拼接结果。
