# 面向人类审查的长程研究记录：两条六批研究线

## 执行前固定设计

目的：用户首先需要理解与事后审查研究过程。本块观察研究者能否留下可定位的“问题/猜想—事前预期—实验—解释修订—后续决定”，以及多批推进中实际出现的科学与接口问题。不以笔记读取次数、文字长度或最高产率代替可审查性，不比较无笔记能力收益。

单位与任务：从空白历史及笔记独立启动 A、B 两条研究线，各预定 6 批，共 12 批；顺序 A1…A6、B1…B6。每条线跨批共享公开 history、完整公共工件和模型版本笔记，互不读取另一条线。每批一个全新 gpt-5.6-sol / medium 原生 CLI/MCP 会话，单研究者、禁用子 Agent/外部工具。批间显式会话重置，不冒充自然压缩或连续未中断上下文。

- A：研究可控操作条件与产率/选择性的关系，检查该关系的适用范围；模型自行选变量、配方、对照、重复和检验，不预设温度路线或改善结果。
- B：研究不同测量读出的可比性与分歧，在公开接口允许范围内区分过程变化和测量配置/采样的影响；模型自行选测试，不要求恢复隐藏公式或真实化学结构。

世界保持同一 reaction/thermal/observation 组合及 world seed 0；批次均从相同公开初态独立开始，既有物理定律不变。仅观测随机流由独立 override 设定为 A:1001…1006、B:2001…2006，避免重复配方必然收到同一噪声。两条研究线不是两个独立物理世界，不进行总体统计推断。每批独立资源账，跨批只汇总实际用量，不声称共享库存。每批均要求 terminate 后 final_assay；其他操作/测量由模型自主选择。

记录职责：模型为人类研究者留下简短公开科学说明。每批首次物理操作前说明当前问题、可检验预期（允许不确定或相互竞争的预期）、选择该实验的理由；关键结果改变认识时更新；批末保留解释、证据引用、未决事项和下一步。普通 Markdown，沿用 read/write/log/diff/restore；不要求每个操作重写，不设强制读检查点或自动注入正文。遗漏记录不阻断实验，按遗漏报告；事后说明不补算事前预测。最终报告与笔记分别保留，报告中已有的解释不因未写入笔记就记为完全缺失。

预算与停止：每批 ≤24 次物理尝试、≤36 次工具请求、≤300 s；每条线最多 1800 s 和 3000000 input+output tokens，会话边界检查用量（含 cached input），软阈值可能被最后一个已启动会话超出。达到任一上限，不再启动该线下一批；不挪用另一条线配额。每批无 runner 自动重试。模型主动提前结束或未完成批次均保留；只要用量完整且无未处理宿主/协议故障，继续预定下一批。宿主/协议故障、CLI 非预算退出、用量缺失或零容差回放失败停止本块，不修改运行中设计，不追加救援轮。每 20 s 输出研究线、批次、已完成/12、工具/物理动作计数、耗时、吞吐和 ETA。

测量与判据：

1. 工程：12/12 终检并 finish_batch、全部已执行轨迹零容差回放、逐步载体/测量资源检查通过，全部工具错误、拒绝、开放或未启动批次保留。缺少笔记不算环境失败。
2. 记录时间与引用：机械列出每批首动作前的新版本、末次物理动作后的新版本、版本事件游标、实际读取/比较/恢复、公开操作理由与终报告；检查笔记中的完整事件 ID 在提交时是否存在。事件存在不证明支持该主张。
3. 人工审查 12 个预定批次，分别检查：事前问题与可检验预期能否定位；事后解释能否关联实际读出；判断/计划改变或保持的理由能否找到；范围、混杂、未决问题是否清楚。分别标记清楚/部分/缺失/未执行并引用证据，不合成智能分数。仅有泛泛“继续探索”不算可检验预期；合理无变化同样可以是结果。
4. 科学观察：公开终检与中间读出、条件变化、重复比较、预测与实际结果、被保留/修订的解释。区分模型当时说法与本次事后分析，不用隐藏真值补模型结论。所有发现均为有限代理世界中的探索性观察。

产物：一个开发 runner 和相关定向测试；`D:/Projects/ChemWorld-local-research/20261011-long-horizon-review/attempt-01` 保存原始 CLI 输出、逐批轨迹/工件、笔记版本、机器摘要与供人阅读的 review.md（原文引用，非模型替写）。本文追加真实结果、人工审查表和边界；TODO 第 9 节为唯一状态源。无需新审计包、正式冻结或论文改写。

接口准备泛化开发 host 的 world/observation seed 参数，旧默认值保持不变；从已有公开数据生成阅览报告，不改写 model-owned notebook。启动前脚本测试发现 `verify_records` 仅在 benchmark 分支恢复 observation seed，组合世界忽略该字段，导致独立观测流回放失败；将该恢复逻辑移至所有入口共有位置，保留记录中的噪声流，不改变物理过程或代理所见读数。19 项记录本/运行器测试与 15 项回放测试通过，覆盖观测噪声与世界分离/精确回放、跨批笔记按需读取、记录时点和引用检查、真实 STDIO。模型实验在该修复及测试完成后启动。

**第一条观察：Agent 没有把转化率增加一概视为研究目标改善。** A1 的 v1 事前提出时间增加可能提高产率、也可能积累副产物；v2 在首段读数后保留该问题；v3 根据后两段数据记录“转化增加、产率趋平、选择性下降”，并决定下一批重复短时条件。A1 最后两个产率读数相差约 0.0057，不能据此确定最优时间。后续人工检查发现 HPLC 工件给出 yield_std=0.012、selectivity_std=0.018；这不是模型当时完成了误差传播的证据，也不是跨批经验置信区间。

**第二条观察：事前预期与后续修订可以清楚区分。** A3 的 v7 在物理操作前写下“升温可能像推进反应时钟一样降低选择性”的预期，以及提高产率并保留选择性的竞争预期。HPLC 后、终检前的 v8 改写 H2：转化上升符合原预期，但选择性上升不符合简单的时间等效解释。v9 再用终检补充，承认较高的降解提示量，且明确 HPLC 与终检一致不等于独立实验重复。随后把下一步从继续加热改为催化剂 B 的成对温度范围检验；A4 的 v10 保存了计划，但这个检验没有执行。可支持的结论是“记录到了证据相关的公开假设修订及后续实验选择”，不是证明模型恢复了真实机理、或笔记导致了更高智能。

**第三条观察：记录本有审查价值，也会带入需要复核的措辞。** A2/A3/A4 的新会话都在第 2 次工具调用读取笔记；A2 另读一次 history，取得 A1 笔记未覆盖的终检事实，再写入 v4。因此 history、笔记与最终报告各有用途。A2 公开理由称“exact repeat”，但实际省略了 A1 的时间零点采样；它的事前笔记同时承认要减少采样扰动。人工应将其解释成同配方/同目标热处理的重复，不能当成完整操作路径重复。A1 的短时读数与长时读数也来自同一釜，不是两份独立重复。A2 与 A3 的动作序列则相同，主要设定差别是温度，另有预设的观测随机流差异。

**第四条观察：仪器间分歧被保留，原因尚未检验。** A1 在 3600 s 的 HPLC/NMR 选择性分别为 0.3587/0.4739（operation-010/012），模型没有把两者直接合并为同一指标的重复测量，也没有宣称其中一个仪器错误。B 线原拟研究这个问题，但未启动，不能从这个单例替它得出结论。

## 故障、后处理与下一步范围

1. **回放缺陷已在启动前修复。** 组合世界也恢复记录中的观测随机种子，34 项启动前定向测试通过；不改变物理过程。
2. **A4 传输根因未确定。** 第 4 个 schema 请求已写入 interactions 的返回结果，宿主没有记录 Python 异常；CLI stderr 同时出现子进程 stderr 非 UTF-8 和连接关闭提示。这个日志只能提示诊断链不完整，不能据此断定故障就是编码造成。仓库外新 STDIO 进程以旧编码环境请求全部九种 schema，再请求 status，返回两份合法 UTF-8 JSON、exit 0；未重现原生 CLI 连接故障，不记为故障已修复。没有因此启动新模型运行。
3. **公开谱图摘要存在确定的展示缺口，待后续修正。** A1 operation-012 的原件含 2048 点 NMR 轴/信号、拟合 standard_error 和噪声说明；简短 spectra_summary 却给出 has_spectral_packet=false，顶层 uncertainty 为空。当前摘要只识别 peak tables/spectra/channels，遗漏新 axis/raw_signal 形式；这不等于原始谱图或全部不确定性缺失。未在本轮运行中改接口，也未把事后查看的原始工件补算为 Agent 已读取。
4. **仅改进事后阅览输出。** 运行结束后将传输失败、未执行但已有笔记的批次、CLI 最后一条公开消息纳入 report；明确区别于成功的 finish_batch。由原始日志重建派生 summary/review，不修改原始 IO、笔记版本、实验条件或成败判据。新增失败报告测试并扩充真实 STDIO 全 schema 查询；最后 35/35 定向测试通过，Ruff 通过。

本轮不扩矩阵、不补性能排行榜、不自动重跑。下一步应先处理实际连接故障及谱图摘要的可见性，再决定是否按新执行块从 A1 重跑原定覆盖；本次 3/12 及失败永久保留。现在已经能支持的记录本定位是：**让人类检验 Agent 当时提出了什么、看到了什么、为什么改变下一步；这项用途不以证明 Agent 自身需要记忆辅助为前提。** 三批成功、三个续接会话读取笔记，尚不足以证明六批/十二批长程可靠性，且没有无笔记对照，不能估计笔记的因果能力收益。
