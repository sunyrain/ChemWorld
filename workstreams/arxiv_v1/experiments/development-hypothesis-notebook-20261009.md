# 假设记录本：职责调整与一次持续会话试用

## 设计

history 是环境保存的操作、观测、失败和资源事实。假设记录本是 Agent 对这些事实的可修改解释：关系/猜想、适用范围、支持与反对证据的引用、竞争解释、可检验后果，以及当前决策和改变决策的条件。普通 Markdown 即可，建议稳定的 H1/H2 标识，不用强制字段或状态机。只摘录理解判断必需的数值，原始 IO 留在 history。

主动维护是研究者职责；出现有后果的新猜想、反证、适用范围变化、混杂或搁置决定时，由 Agent 自定是否与何时提交。不逐步打卡、不按字数/版本数奖励、不用笔记门禁阻止实验。记录简短科学理由和可检验预测，不要求披露私有思维链。事后解释不冒充事前预测。

沿用 read/write/log/diff/restore，read/diff 才提供正文；状态和新会话只提供版本/公开事件定位信息，不注入正文或自动总结。write 提交完整当前稿；restore 新增版本、保留原证据边界，不回滚环境或删除旧解释。完整旧版保留，不要求当前稿无限累积。宿主事件游标证明提交时点，不证明引用真实或解释正确，须另核对。

## 固定开发试用（执行前写定）

问题：区分 history 与假设记录本并减少重复上下文后，Agent 能否自主形成、修订、按需取回假设，并将其联系到后续实验？同时核对实际路径的环境事务、测量资源与精确回放。此块不是能力比较或正式论文证据。

单位：一个研究运行，两批独立 reaction/thermal/observation 组合，同 seed 0；既有 Codex subscription 默认 gpt-5.6-sol、medium。每批一个持续原生 MCP 工具会话；第二批是全新会话，只有共同任务与公共初态，history 和假设记录本按需读取。两批的条件与科学解释由 Agent 自选。任务覆盖混合介质、热处理、至少一次配置 NMR 与 NMR 读出，以及两批 terminate 后 measure(instrument=final_assay)。这是请求的覆盖，不声称自发选择这些功能。

限额：每批 24 次物理尝试，含回滚；全程最多 60 次工具请求、20 分钟、每会话最多 10 分钟；观测累计 300000 input+output tokens 后不启动下一会话。CLI 可能只在整轮结束报告用量，故 token 限额是会话边界软阈值，不能保证轮内硬截断。无 runner 自动重试、无因表现不佳追加样本。协议故障/缺失 usage/预算停止保留全部已执行结果；平台缺陷修复后如需再试，另目录从第一批开始，旧结果保留。

测量：真实工具调用与所有错误、Agent 公开决策理由、笔记版本/事件时点/读取与引用、两批操作/提交/回滚/终检、两批条件变化、逐步载体守恒、测量时间/费用/采样与精确回放；CLI JSONL、终态用量、超时或用量缺失分别记录。完整公开返回与原始信号可按需查阅，压缩展示不改变世界输出。

工程通过：2/2 批终检、无未处理协议/宿主故障、覆盖达成、每步载体残差 ≤1e-10 L、配置 NMR 的时间/费用/扣样符合合同、全部保留轨迹零容差回放。无笔记/未读笔记/未使用 diff 或 restore 不是环境失败。另报告笔记是否在实验前提出可检验后果、是否随证据修订、是否被后续会话主动读取、是否可见地影响实际选择；不能仅凭调用或自述判定改善理解/长程能力。两批不同条件的单次结果不提供重复性或因果机制证据。

输出：复用现有版本存储，新增角色说明、持续会话开发入口及定向测试；仓库外 `D:/Projects/ChemWorld-local-research/20261009-hypothesis-notebook/attempt-NN/` 保存原始模型输出、笔记、完整公开工件、轨迹、机器摘要及失败。本文追加设计评估与实际结果；TODO 第 9 节是唯一进度源。旧 R45 的失败及冻结论文保持原样。

## 首轮接入缺陷及限定修复

`attempt-01` 保留 1/2 批终检、10/10 提交、零容差回放。模型事前主动写入一个温度对照假设；第一次使用空事件引用被正常拒绝，第二次成功提交。终检后模型尝试提交有证据引用的修订，但 Windows 原生 MCP 子进程未继承 UTF-8 输入设置，含长横线的文本被误解码为 surrogate，写请求日志时报错，连接关闭。该修订与 finish_batch 都未成功提交，不能把 CLI 最终文字当持久笔记。另保留 1 次 artifact 超页长错误。CLI 已报告 548114 tokens，其中 479360 为 cached input；二者不能相减后冒充原定总 token 口径。没有启动第二批。

修复 STDIO 显式 UTF-8，加入故意使用旧编码环境的子进程回归。动作 schema 改为一次查询列表，减少相同初始化的来回；说明事前写作应省略 reviewed_through。科学问题、模型、两批覆盖、预算及评价不变；在 `attempt-02` 从第一批重跑，保留原目录。摘要判据按执行前定义区分正常返回的可恢复输入错误与未处理宿主/协议故障，不把任意工具误用当成环境崩溃；所有错误仍列出。第二轮仍按会话边界总 token 阈值停止，不为跑完两批放宽预算。

## 修复后结果：单批闭环，跨会话使用尚未验证

`attempt-02` 在 109.41 s 内完成 18 次工具调用、11/11 物理操作提交、1/2 批终检，0 次操作回滚、0 次工具输入错误、0 次 transport failure，finish_batch 成功。会话结束报告 384053 tokens（380881 input，3172 output；input 内含 348800 cached），在第二批启动前触发原定 300000 软阈值。**整体两批验收为 failed；第二批没有开始，也没有结果。** 未追加第三轮、未修改阈值、未把 cached token 排除后重算预算。原生持续会话仍不等于低总 token 开销；不能宣称已解决长程成本或恢复问题。

真正观察到的内容演化：

1. **事前**：固定投料、介质、催化剂、时间与搅拌，拟比较 330 K 与 390 K 的设定；明确不知道升温会提高转化还是增加副反应。这个事前计划不是正式预注册研究，尽管模型自行用了 “preregistered” 一词。
2. **普通测量后**：HPLC conversion≈0.9974、yield≈0.3637，模型提出“转化已经接近饱和，选择性可能限制产率”；同时注意到 NMR selectivity≈0.5064 与 HPLC≈0.3783 不一致，将其保留为尚未解释的仪器/代理读出问题。它没有据此声称识别了真实结构或机制。
3. **终检后**：将 final-assay yield≈0.36937 定为基线，保留温度假设未决，并写明第二批保持配方和处理顺序、只改变温度；其他条件若改变，应视为混杂。版本中给出足够的未来配方是待执行的决策说明，不是逐步复制历史。

需要防止夸大：三次写入是在明确赋予维护职责之后发生，证明的是“角色指令下、模型自定时机的维护”，不是完全无提示的自发行为。第 2 版后的实际动作仍是原定 terminate/final assay；第二批未执行，**未观察到假设修订改变后续实验选择**。没有无笔记对照，不能与 R45 的 0 次写入构成能力提升估计，也不能宣称提高理解或预测。

## 设计收束

保留普通 Markdown 和 Git 式版本，不再增加一个自动整理实验流水账的层。当前推荐内容仍是“主张与范围—证据引用/反证—竞争解释—可检验后果—下一步决策”；这是建议组织方式，不是每步强制表格。允许尚无证据的猜想，提交时点由宿主记录；在假设内容有变化时由模型自己更新。

本轮暴露两个边界，明确列为使用说明，不再扩实验：

- 模型最后把“高于/低于 0.36937”直接作为效应方向标准，这不足以排除观测噪声。记录本应允许并鼓励写清测量不确定性及无法区分的情形；当前试用没有得到可靠温度效应，更没有机制结论。任何比较阈值都不能在看见第二批结果之后补写成事前标准。
- history 适合查事实，记录本适合取回解释；原始谱图仍应按需读取。当前完整公开工件较大，未来若优化查询，优先提供已有 processed_estimate/raw_signal 的字段选择，避免为了找一个指标翻整个谱图数组。无需为此新增知识图谱、假设状态 API 或自动摘要，也不在本轮继续扩功能。

本轮交付的角色说明位于 `src/chemworld/agents/hypothesis_notebook.py`；试用入口是 `uv run --no-sync -m scripts.run_hypothesis_notebook_pilot --output <new-external-directory>`。版本存储沿用 `ExperimentDocumentWorkspace`，未改 Work II 正式 MCP 协议。原始输入/输出、三份笔记及 `notebook-review.json`、`summary.json`、`fresh-process-replay.json` 在上述仓库外目录；集中测试记录为同级 `acceptance-tests.xml`。两个尝试已报告合计 932167 tokens，不据订阅用量推算美元价格。
