# S0-20 静态科学优化 horizon 诊断结果

日期：2026-07-26

## 1. 核心结论

1. 电化学 leaderboard score 的数学上界是 `1.0`。这是评分公式的归一化上界，不是当前物理参数空间中已证明可达的分数。
2. 任务文件中的 `0.58` 是历史 success threshold，不是理论上界，也尚未被当前修正后的命名电化学世界校准为稳定可达阈值。
3. 当前世界 seed 0 的 100 点本地随机响应面最好观测分数是 `0.4954696104`；该配方在与最终推荐相同的三次配对盲验证合同下均值为 `0.4859999546`。它只是 best-known sampled reference，不是 oracle。
4. WellAU `gpt-5.6-sol` medium 的 20 轮探索最好分数为 `0.4752352234`，最终提交配方的三次盲验证均值为 `0.4507878303`。
5. 前 8 轮最好分数只有 `0.1080936013`，第 12 轮首次超过 `0.3`，第 13 轮首次超过 `0.45`，第 15 轮达到全程最好值。因此 8 轮不是一个已有证据支持的自然终点。
6. 这不是“原 8 轮策略机械追加 12 轮”：模型从第一轮就知道 horizon 是 20，因而会改变探索节奏。结果证明 20 轮已知-horizon 方法能获得明显更好的最终方案，但不能单独识别纯粹的额外轮次因果效应。

## 4. 最终方法与验证

模型选择第 15 轮的已测试配方作为最终方法：

```text
electrolyte_profile = 2
solvent = 0
reagent_amount_mol = 0.012
probe_potential_V = 0.80
probe_current_mA = 25.0
probe_duration_s = 300
controlled_potential_V = 1.05
controlled_current_mA = 54.0
controlled_duration_s = 1650
```

该轮观测分数为 `0.4752352234`。最终推荐和 incumbent 是同一已测试配方，因此两者三次盲验证均值相同：

- 盲验证分数：`0.4680877294`, `0.4624946015`, `0.4217811600`
- 均值：`0.4507878303`
- 样本标准差：`0.0252756990`
- 相对 incumbent 增益：`0.0`

这里的 `gain=0` 不是模型没有改进，而是最终推荐正确地复用了探索期 incumbent；改进已经体现在 incumbent 本身从早期低分区域提升到约 `0.45-0.48`。

## 5. 上界与阈值判断

当前应区分四个量：

| 名称 | 数值 | 含义 |
|---|---:|---|
| 数学评分上界 | 1.0 | 所有正向组件为 1、代价风险为 0 时的公式上界 |
| 历史任务阈值 | 0.58 | 配置中的 success threshold，尚未完成当前世界校准 |
| seed 0 best-known sampled 盲验证均值 | 0.486000 | 100 点随机响应面最好配方的三次配对验证；非 oracle |
| S0-20 模型最终盲验证均值 | 0.450788 | 本次模型最终提交方法的主要可执行结果 |

本地 sampled 配方为 solvent 0 / electrolyte profile 2，约 `1.046 V, 17.07 mA, 321 s` probe，随后 `1.209 V, 91.09 mA, 1200 s` controlled stage。其三次盲验证为 `0.488496`, `0.482903`, `0.486600`。

因此，目前不能声称当前世界实际可达到 `1.0`，也不能声称 `0.58` 已被证明合理。更稳妥的说法是：seed 0 的已验证 best-known 区间已经接近 `0.49`，而模型在 20 轮内达到约 `0.45` 的盲验证表现。

旧 r3 的 `0.3650188` 来自电化学物种/运行契约修正前的归一化向量接口，不能作为当前命名电化学世界的上界或直接基线。

## 8. 对 horizon 的当前判断

单次结果已经足以否定“8 是有理论依据的固定值”。但还不足以选择新的正式 horizon。下一步应把 horizon 当作待校准实验变量，至少比较 `8/12/16/20`，并分别报告：

- 最终盲验证分数；
- 首次达到固定绝对阈值的轮次；
- best-so-far AUC；
- provider token 与物理实验成本；
- 已知 horizon 对探索节奏的行为影响。

若正式目标是比较方法的 anytime 优化能力，应使用统一最大预算并在固定 checkpoints 读出 incumbent，而不是让不同方法因显式知道不同终点而形成不同策略后再把结果解释成纯轮次数效应。
