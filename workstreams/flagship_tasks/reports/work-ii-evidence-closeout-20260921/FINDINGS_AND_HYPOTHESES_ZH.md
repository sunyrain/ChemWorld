**目录规模：183 个编号条目**，包括 79 项分体系结果/案例与边界、20 项校准或跨体系组合判断、17 项平台/方法、24 条待验证假设、19 条历史结果、8 条工程经验和 16 张候选故事卡。它们相互引用，不是 183 个独立科学发现。首次阅读建议先看第 15 节故事卡，再回查第 3–8 节事实和第 11 节假设；逐项数字在第 17 节同文件折叠表内。

## 0. 阅读方式、证据等级与共同边界

| 标记 | 含义 | 可如何使用 |
|---|---|---|
| 事实 | 当前保存的数值或执行记录，包含原设计统计和明确标注的事后统计 | 可作描述性结果；不自动支持因果解释或总体显著性 |
| 案例 | 已核查的特定来源、主张或预测轨迹 | 可解释现象；不能用选定案例估计发生率 |
| 组合 | 将多个事实放在一起得到的概念性判断 | 可作论证；不构成额外样本或已经识别的共同原因 |
| 假设 | 尚未验证的机制解释或可检验预测 | 必须保留竞争解释及可推翻条件 |
| 平台/方法 | 已实现能力、评价原则或设计边界 | 是贡献或解释前提，不冒充 agent 科学发现 |
| 历史 | 旧协议、其他模型、先导或已替代数据中的结果 | 只按原身份引用，不升级为当前主矩阵证据 |
| 工程 | 执行、接口、计量、修复经验 | 不归因于模型的科学能力 |

## 16. 我们怎样逐条判断价值

评估时先问条目是什么，再决定怎么用；不把“好听”当证据强度。建议对 S-01–S-16 逐张填写，下钻到对应事实/假设编号。

| 维度 | 需要回答的问题 | 记录方式 |
|---|---|---|
| 证据 | 数值是否重复出现在多个世界？是否只选了极端例子？ | 强 / 中 / 弱，并写事实编号 |
| 新意 | 相比“优化≠预测”“先验有时有害”，新增了什么具体边界或机制问题？ | 一句新增认识；没有则写“支持性结果” |
| 科学意义 | 是否解释自主研究的一个关键环节，还是只报告指标差异？ | 写受影响的研究能力 |
| 替代解释 | 最容易被审稿人提出的解释是什么，现有材料能否区分？ | 写最强竞争解释，不只列弱反驳 |
| 因果距离 | 当前是结果、轨迹关联，还是可识别的干预效应？ | 明确等级；不能靠叙述提升 |
| 互补与重复 | 是否与另一故事使用同一批证据、只换词？ | 合并到哪张卡，或为何保留 |
| 补强成本 | 只需重算/读轨迹，还是需要新的独立实验？ | 无新增 / 现有材料分析 / 新受控块 |
| 论文角色 | 能否承载主结论，还是提供成功案例、反例或边界？ | 主线 / 支持 / 附录 / 未来 / 不采用 |

**讨论记录模板：** `S-__：决定__；核心证据__；最大替代解释__；待做分析__；可写的一句话__。` 暂不机械相加成总分，尤其不能用高新意抵消证据缺口。
