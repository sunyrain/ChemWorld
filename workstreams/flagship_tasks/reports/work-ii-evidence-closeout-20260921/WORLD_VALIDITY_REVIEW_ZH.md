# 回顾性分析一：世界是否合理，任务是否可学

日期：2026-09-21。性质：读取当前结果、公开合同、设计说明及执行代码后的作者分析。
没有新模型调用、模拟器执行、基准重算或参数修改；下面的补分析与对照均为建议，未报告为已完成。

## 1. 当前判断

“世界或任务设计导致 agent 失败”是需要实质回应的替代解释。现有证据能反驳“全部任务没有信号、任何方法都无从预测”的笼统判断，但不能证明每个响应、每个新条件都可由十二次自主实验辨识，更不能把所有误差归因于推理缺陷。

必须区分三个层次：

- **知道世界如何生成结果**：后台固定方程与参数，因而可以生成真值。
- **存在有用的公开实验**：某些合法干预会产生可分辨响应，或达到目标。
- **在给定信息、预算和接口下可以发现有用规律**：参与者有机会找到相关干预，并从有限观测形成有预测价值的模型。

前两项不能自动推出第三项。参考配方证明可行性；使用隐藏参数的 oracle 证明某种性能上界；它们都不能替代只使用公开信息的学习对照。预测可学也不要求唯一恢复模拟器内部结构，观测等价的解释应当被允许。

## 2. 审稿质疑应拆成可检验问题

| 质疑 | 现有证据可回应到哪里 | 仍缺的证据或分析 |
|---|---|---|
| 实现错误、物料不守恒、跨步状态丢失 | 各块的执行、资源、重放检查及已记录修复；能定位操作是否按合同发生 | 对关键结论所依赖的实际响应链逐项核对；重放同一错误不是独立物理验证 |
| 世界没有足够响应差异，结果全由噪声决定 | EQ 的固定查询存在世界分离与响应跨度；C 有可行配方及部分可分辨干预；PA 有较好预测 | 这些证据是否适用于 agent 实际获取的观测及具体响应，而非只适用于主持者选的探针 |
| 十二次根本学不了，需要隐藏答案 | C 同源均值对纯度更好；PA/24 明显改善；部分 RX 先验条件更好 | 匹配公开信息和预算的简单学习者；给定实际历史的预测歧义，而非只证明隐藏家族参数不同 |
| 工具架构消耗认知或操作资源 | 当前接口与实验自由度有明确合同；成功例说明不是整体不可执行 | 单位、状态摘要、采样效应、实际温度与指令温度、调用粒度、资源拒绝是否解释特定错误 |
| 测试条件偏离合理探索域，或人为挑选困难题 | 查询在 source 执行前固定；EQ 查询修订发生在 provider 调用之前，有保留记录 | 按公开可达性、已采样范围、机制区间及响应跨度分解成绩；独立查询上的复现 |
| 只是模拟器特有规律，没有化学意义 | 模块与物理/过程约束提供受控抽象；适合研究有限信息下的干预预测 | 关键规律的独立解析/数值参照、模块适用域；真实化学外推需要额外外部验证 |
| 五个世界只是在复制一种人工规律 | 多体系结果方向不同，存在成功与失败 | 明确参数变化与结构变化的区别；不能把同一拓扑的五个参数设置当五种独立机理 |

不把这些问题转化为一套新的全局 gate。每条结论只需对应它实际依赖的效度证据，缺口如实标明。

## 3. 已有 gate 的准确含义

第一篇冻结资格记录覆盖 64/64 task-world units、1,786/1,786 recipes、192/192 invalid actions，以及组合、模块和接口测试。这些是有限域内的实现和模型一致性证据。`configs/current.json` 也明确区分冻结发布与后来发生变化的开发执行面，不能把早期冻结检查移作所有后续代码的证书。

**C 的现有资格比“能够运行”更强，但仍不是学习证明。** v3 参考设计包含材料、晶种、冷却、热历史、继续生长和上游投料六对问题。五个资格世界均通过，至少存在合格回收配方，干预对有 5/6 或 6/6 达到已设响应分辨规则。源 agent 不获得主持者可行配方。它证明一些目标可达和干预有效，不证明 agent 能在十二次内发现整套长程工艺，也不保证每对干预在每项响应上都可辨。

**EQ/P 的两个 gate 名称容易被过度解读。** 当前被 v2 runner 调用的基础实现中：

- `active_information_gain` 比较固定查询里最好探针的相邻世界均值差/噪声尺度与阈值；它没有测量一个公开学习者序贯选实验后的后验信息增益。
- `misindexed_publicly_refutable` 比较真实隐藏 pKa 与错配资料区间端点的距离；单独这一项没有构造一条由参与者观测到反驳资料的推导。
- `aligned_compatible` 在这个布尔检查里验证真实 pKa 落入 Aligned 区间；不能据其名字推断整个资料已被完全独立验证。

响应分离、参数错配、等价路径一致性等合在一起提供有价值的设计检查，但不能直接写成“已证明公开可辨识”“每个 agent 都拿到了充分反证”。保留原报告与名字，当前说明使用实际计算含义，不静默修改已冻结 gate。

## 4. 各体系的回应强度不同

### C：已有最直接的同数据证据，但纯度任务有低变异边界

同一场 source 的公开最终观测均值，在纯度预测上胜过 agent **30/30** 场；agent 的回收预测反而胜过它 **26/30** 场。这个比较器没有额外实验或隐藏真值参与拟合。因此，不能将所有纯度误差解释成“当前数据对任何公开预测方法都毫无用处”。

但是，该结果不证明数据唯一识别了真机理，也不证明一个事前理性的学习者一定应该选择均值。基线优势是在实际固定查询上测得，查询纯度变化很小（平均世界内跨度约 0.02442），均值天然占优。强一些的回应需要保留该事实，同时说明模型为什么预测远离观测，并检查误差是否跨响应、跨独立条件持续。

C 的合理结论是“特定稳定响应的预测出现了可量化、可避免于一个简单比较器的偏差”，不是“复杂结晶机理已充分可辨而 agent 全面失学”。回收、粒径、细粉应分别讨论；不能用纯度均值结果替代它们的可学性论证。

### EQ/P：先检查可辨识性，再讨论跨区间失效的原因

所有十五场 source 的最低名义浓度均高于 0.018 M，最稀三题约在 $10^{-4}$–$10^{-5}$ M。五个世界均出现 Aligned 在其他九题较好、最稀三题较差的反转。这支持“信息效果依赖查询区间”，还不能说明 Aligned 已见过转折证据却拒绝更新。

若两个符合公开背景的关系在实际平台区数据内几乎等价，却在稀释区间分叉，那么 point prediction 对隐藏真值的偏离不自动等同于推理错误。应同时评价哪些替代解释仍被允许、模型是否承认歧义，以及区间是否合理；不能要求恢复未被观测识别的唯一内部机制。

Opaque 的预测更好也不是充分证据：它可能利用一般化学先验作出了恰好较准的外推。选例中的 Q 确实增加了 K1 以外的推理，不能回填成源实验阶段已经形成的发现。

此外，EQ/P 五世界使用同一 base seed、同一沉淀常数和共同结构，主要改变有效酸碱常数，pKa 从约 4.6594 到 5.3794。应称为该受控家族内五个参数设置上的一致现象，而非五种独立化学机制的广泛复现。

**可追溯的选题变化也需要披露。** v1 网格因响应跨度不足、常数预测具有竞争力而失败；v1.1 保留物理参数、先验、预算与阈值，扩大查询浓度覆盖。记录显示修订前 provider 调用为零。它不是看到 agent 失败后挑题，但仍说明最终测试有意包含跨区间挑战。合法范围、公开任务说明和评分解释应与这种挑战一致。

### PA、RX：用于表明条件性成功，不用于替别的体系证明可学

PA 的有机相预测 MAE 从 12 批的 0.08291 降至 24 批的 0.02379，13/15 配对改善。RX/P 的 Aligned 在发现和优化任务中各 4/5 世界优于 Opaque。这说明 ChemWorld 内并非所有任务都没有可利用规律。

它们不能证明 C 的复杂过程或 EQ 的极稀区间在同一预算下也可学。模型、操作资源和测量预算都必须结合具体体系来解释。

### EC 与 P：任务达成证据强于“机制已学会”的证据

EC 的优化指令改善复测 26/30、改善 score 预测 14/30，直接支持评价维度应分开，不能单靠这个结果判定错误发生在建模阶段。P 的质量合格和回收率分离说明任务目标需要约束，但 3/5 对 0/5 的单次阈值结果含噪声、样本小，也不是总体学得/没学得的分类。

## 5. 应该做的最小回顾性分析

### 第一优先：关键主张的证据—查询对应

优先 C、EQ/P，其次 EC，再扩展全部体系。复用已有 source、K1、Q、K2、参考值和资源记录，逐条建立：

> 主张或响应 → 实际干预与观测 → 源报告承认的适用域 → 查询变化 → 点预测及区间 → 可竞争解释。

把“未取得相关证据”“证据支持多个解释”“有观测但预测明显偏离”“单位/工具/状态理解错误”分开；允许一例同时有多种原因，允许暂无法判断。不能仅凭知道真值就将某场归为推理错误，也不以 K2 事后文字替代源阶段行为证据。

先检查公共可达性和合同再计算覆盖：输入数值是否可通过公开接口执行，资源是否允许，任务说明是否合理提示这一类干预。区间距离、响应区域和噪声信息比“试了多少种参数”更有用。分组标准先写清楚，全部世界和相反例一起报告。

### 第二优先：给定历史的预测歧义

对 EQ/P、C 等关键解释，在明确的、化学上有理由的候选模型范围内，寻找能同时拟合实际公开观测的不同关系，再看它们对 Q 的分歧。候选模型是**评估者侧的诊断工具**，不向 agent 提供菜单、不限制其机理表达，也不能只使用已知正确的模拟器方程。

若一组模型在观测噪声范围内都解释 source，却对新条件给出很不同的结果，就记录该查询存在证据歧义。若多个公共模型在同一数据上给出相近预测、而 agent 系统性偏离，才更有理由定位证据使用问题。模型范围有限时，没有找到歧义不等于证明唯一可辨识；构造任意复杂插值函数也不能算有意义的反证。

### 第三优先：公平的公开信息比较器

扩展现有同源均值/最近邻时，明确比较器拿到的先验、过程观测和最终测量分别是什么。基线选择、调参和模型筛选不能使用将要报告的 Q 真值。可以在 source 内部验证，但必须说明外推区间仍未得到验证。

当前 Q 结果已经揭盲，作者无法通过事后声明恢复原先的盲性。因此新增比较器在这一数据集上仍应标为探索性；若要确认模型选择规则的泛化，需要冻结规则后另用独立查询或世界评估。

隐藏方程、精确隐藏参数或先看过 query 真值的解析 predictor，只能作为 oracle/工程参照，不能当作“普通学习者十二次能学会”的证据。公平的自主基线还必须从公开信息选择实验，并使用相同批次及测量预算；固定已有轨迹的基线只回答利用这些数据的能力。

## 6. 若回顾性证据不足，再做小规模定向实验

以下是供后续设计的新实验，不属于本次已完成的回顾性分析。执行前形成新的简短实验块说明，固定问题、覆盖与评价。旧实验保留，不因补实验更有利而替换。

| 对照 | 固定什么、改变什么 | 能回答什么 | 不能越界解释什么 |
|---|---|---|---|
| 固定证据的推断对照 | 所有条件读同一份公开实验历史，只改变资料臂；无新增实验 | 资料是否在相同证据下改变预测与区间 | 与原完整自主研究的差异不能直接当纯报告压缩效应 |
| 固定预算的覆盖对照 | 同样 12 次，预先固定一种通用覆盖策略与自主选择比较，查询继续隐藏 | 系统是否存在可实现的、预算内更有信息的取证方式 | 不把用真值挑选的最佳转折点当一般公开策略；不能保证自由探索一定找到 |
| 接口表述对照 | 同世界、同信息和物理操作，规范单位与状态呈现；明确保持费用和反馈时序的部分 | 某类错误是否依赖表示或操作负担 | 高层工具若改变粒度、成本、可用推断信息，必须作为不同干预披露 |
| 独立查询/参数复现 | 原设计完成后固定新的范围与抽样规则，再执行新块 | 现象是否依赖原查询和参数选择 | 只换观察噪声不能声称新的结构世界验证 |

无需要求平均 agent 得高分才叫合理任务。难度高而公共证据确实可达，是合理的研究对象；不可辨识性本身也可研究，但评价目标应包含辨认歧义与合理不确定性，而不是只惩罚未猜中隐藏内部机制。

## 7. 对审稿人的现阶段回应草稿

> 我们同意，模拟器能够生成确定真值或通过执行检查，并不足以证明有限预算下的机制可辨识性。本文将内部执行有效性、任务可达性和基于实际观测的泛化能力区分报告。现有研究包含可观测的干预响应、成功的研究条件，以及使用 agent 自身数据的公开预测参照。例如，在结晶中，观察均值的纯度预测优于所有三十场 agent 预测，而 agent 的回收预测在二十六场优于该均值，说明预测偏差具有响应选择性。与此同时，我们不把稀释区间的预测错误直接解释为拒绝已出现的反证：所有平衡源实验都位于较高浓度区，跨区间推断可能存在歧义。因此，我们的结论限定为这些受控任务中的操作、预测与不确定性之间的分离，以及信息效果对区间和响应的依赖；进一步的采样与推断因果归因需要匹配证据的对照。模型的内部一致性亦不替代真实化学外部验证。

上段只描述现有证据。后续做完对应分析后再增加具体表格、比较器或结果，不能现在预写为已完成的回应。

ICLR 版重点补足评价的构念效度、公共预算内的可学性及强比较器。NCS Article 除此之外还应清楚展示所用物理近似的适用域和科学问题的重要性；不能仅用“这只是 benchmark”回应化学模型的实质问题。
