## 1. 解释活动可以改变研究取得证据的方式

EQ repeat-02 / W05-Aligned 提供了实际行动支持的连续正例。初始计划在稀释前用 pH meter、稀释后用 final assay；前六批确实如此。v2 在游标 36 指出组成变化与仪器差异混杂，并提出把两次测量移到最终组成。后六批实际执行了这个变化：仪器之间的加料次数从每批一次变为零。末端笔记与封存 K1 保留了小稀释效应尚未分辨的判断，Q 则明确改用 final-assay-only 系列形成预测。

这支持“发现解释上的混杂—修改证据获取—限定认识范围”的公开过程。pH meter 每次会取走 30 μL，所以准确表述是相同名义制备条件、期间无主动加料，不能称完整状态相同。它也没有独立区分所有化学机制，或证明仪器偏差而非随机误差是唯一原因。

这条轨迹也不是全程无误：K2称没有做同终态加料顺序比较，而 EQS 指出了第7/12批的相关对照。Q 对极稀区仍延伸局部斜率。设计反思、限定性认识和新外推的不确定性可以同时出现，不能给整场贴单一“成功/失败”标签。

## 2. 看似完整的解释链可能建立在没有执行的对照上

C repeat-02 / W04-Aligned 原先看似一个很强的化学机制案例。420 K 批次回收约 0.673；两次 440 K 批次回收只有 0.0079、0.0090；随后 430 K 批次恢复到 0.675、0.678。v4据此提出非结晶产品状态或溶解度历史变化，并安排430 K边界试验。

执行核对改变了结论：两次440 K之后请求的265 K与270 K冷却在游标107、118都 **rolled_back**。原始记录显示拒绝原因为 `cool_crystallize_reference_temperature_in_solubility_domain`，时间与温度增量均为零；比较批次的冷却则成功提交。因此所谓“改变冷却终点仍失败”的阴性对照从未完成，不能据此归因于440 K造成化学变化。

该错配随后取得了更强的认识地位：K1把它写成重复发生的结晶能力崩塌；K2在“直接观测支持”下声称440 K历史造成回收崩塌，并提议440 K/300 s区分热剂量与峰温机制。这个后续实验只被提出，未被执行。它展示的是**请求被当作已执行处理、执行错配进入解释、解释又组织下一项检验计划**，并不证明自我确认循环，也不证明430–440 K化学边界。

## 3. 对证据是否真正成立，存在方向不同的研究路径

加种案例提供了与上述过程相关但不相同的对照：

| 会话 | 笔记中的关键处理 | 已提交处理 | 公开认识的走向 |
|---|---|---|---|
| C repeat-02 / W02-Aligned | 累积约1 g种量；批7/9/10/11 | 每批0.05 g；各19次额外请求受拒 | v4明确撤回高剂量已执行叙述；K1/K2仍保留高剂量未检验。 |
| C repeat-02 / W03-Aligned | 批10累积1 g | 0.05 g；19次受拒 | 同期笔记、K1和K2将其作为高剂量阴性证据。 |
| C repeat-03 / W02-Aligned | 批7暖种0.5 g、批12冷种3 g | 各0.05 g；分别9、59次受拒 | 终点笔记把计划剂量当作已做，不能支持其剂量结论。 |
| C repeat-03 / W03-Aligned | 批2与8的大累积种量 | 各0.05 g；分别19、39次受拒 | 错误剂量叙述与后续真实可行的联合配方并存。 |

这四场不是随机化的“好策略/坏策略”比较。它们说明仅凭科学语言、公式或低预测误差无法判定解释有何实验基础。准确识别实际处理本身参与了认识形成；操作成功也不能自动修复先前的证据错配。

## 4. 局部关系、失败修订和认识范围同样是实质结果

并非所有重要转变都必须称为机制反绎。C repeat-02 / W05-Aligned 在末批前预测0.065 L中间体积可使细粉合格，结果约0.6013，随后撤回预期并推荐较早的合格批次。这是有后果的局部预测与修订。C repeat-01 / W05-Aligned 在回热方案失败后进一步降低投料并取得可行方案，但固定催化剂量同时改变了催化剂/底物比例，不能唯一归因为过饱和度下降。

同样，EQ中提出“另一个加料命令代表不同活性组分”的解释，并不意味着实际材料被区分。原执行合同下 `add_reagent` 与 `add_component(0)`进入同一种feed A；操作名不同不能代替化学干预不同。解释检验必须落实到实际物理处理与能够区分的观测。

## 对论文及新实验的意义

现有材料足以把“解释如何形成并参与研究”从事后评分中分离出来：既有根据发现调整证据获取的过程，也有证据范围正确收窄、局部预测被撤回、未执行对照被提升为因果依据的过程。它们不要求统一成一个自我确认机制，也不要求以改进智能体作为结尾。

尚不能仅由这些既有轨迹证明：智能体能够稳定地在初始观测相近的不同机制世界间，自主取得真正有区分力的证据并形成可迁移解释。另行完成的30场匹配机制世界研究针对这一缺口，见[综合报告](../REPORT.md)。该新队列分开评价预先提出的辨别意图、实际操作的区分力、公开解释修订，以及留出条件下的使用，未用行动数量或末端预测表现代替全部过程，也不改变本文件的105场历史队列范围。
