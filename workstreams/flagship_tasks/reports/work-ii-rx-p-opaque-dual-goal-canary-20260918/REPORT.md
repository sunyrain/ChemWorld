# RX-P Opaque 双目标开发 canary 结果

逐阶段叙事、真实提示、十二批决策链及代表性预测—真值对照见[详细报告](REPORT_DETAILED.md)。

日期：2026-09-18。状态：开发运行完成；原始后测失败保留，同 thread 修复链完成。该结果不是正式 benchmark，也不能外推到其他世界、先验臂或新的 autocatalytic RX 任务。

## 结论先行

`RX-W01 × P × Opaque` 已按两个独立来源跑通：机理探索与安全约束优化各完成 12/12 批。合计 24 次 HPLC、24 次终检、169 个 Agent 动作、0 回滚；两个来源均 exact replay 通过，封存建议均独立复测成功。K1 机理报告、12 条固定条件定量盲预测 Q、K2 三问复盘也均已取得。

最值得保留的科学结果有三点：

1. 两个独立来源都识别出有限热暴露窗口，而不是追求完全转化。共同的最简解释是 `R→P` 与 `R→B` 竞争，并可能有 `P→D` 后续损失；但催化剂失活、产物抑制和传热滞后仍是合理竞争解释。
2. 优化来源在固定配方内把窗口收敛到约 408–410 K、2200–2500 s；推荐 408 K/2300 s 的 safe score 为 0.4003，独立复测为 0.3974。
3. 机理来源通过时间、催化剂、溶剂和淬灭对照发现：420 K/2200 s 后立即淬灭主要降低风险而非提高化学收率。其推荐 score 为 0.4388，独立复测 0.4384；风险为 0.1491。

两者不能直接解释为“机理目标优于优化目标”。这是单世界、单来源、不同自主实验路径；机理来源恰好测试了优化来源没有测试的淬灭操作。

推荐为批12：cat 1、solvent 2、420 K、2200 s、立即 quench。原观测 score .43884，独立复测 .43845；复测 yield .71444、conversion .94346、selectivity .77562、risk .14909。

## K2 暴露出的关键问题

两个来源都没有把 `R→P, R→B, P→D` 唯一识别出来。最重要的竞争解释是催化剂失活、产物抑制、传热滞后和多个副产物通道。

机理来源提出的下一实验是：420 K/2200 s 后补加同种催化剂，再延长到累计 5000 s，用目标物是否继续下降、残余反应物是否继续转化区分失活、并行副反应与 `P→D`。

优化来源提出的下一实验是：固定 410 K，在同一釜 2300 s 与 5700 s 两次 HPLC，再终检；它能直接观察目标峰是在后段下降、停滞还是继续增长。这比再做一个孤立终点更有判别力，但仍不能单独证明催化剂失活。

- posttest-repair-v1/v2：首次恢复尝试没有正确绑定隔离 `CODEX_HOME`/会话索引，失败保留，无模型科学输出。

v4 主运行约 25.6 分钟；成功的四个修复 turn 合计约 297.7 秒。接入排障和早期失败另计。该耗时不能直接与旧 EC 的单场约 8.5 分钟比较，因为当前 CLI 路由、两来源串行、失败 Q 和同 thread 修复均计入本次过程。

## 边界与下一步

本 canary 只能回答“RX-P Opaque 单世界能否按双目标整链跑通”，答案是可以，但当前 runner 需要保留 Code Mode MCP 路由和足够的后测计算预算。

它不能回答 Opaque、Aligned、MisIndexed 的先验效应，也不能证明 `catalyst_deactivation`。下一步若继续，优先不是立刻扩 A/M，而是先预注册一个小型 quench/失活判别块：比较 408 K/2300 s 与 420 K/2200 s，各自有/无 quench，并加入一次补催化剂或同釜时间轨迹。只有这一步确认后，再决定是否展开三臂或迁移到新的 autocatalytic RX 任务。
