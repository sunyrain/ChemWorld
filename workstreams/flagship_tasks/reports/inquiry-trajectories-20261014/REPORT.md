## 解释范围

- Temporal windows measure available evidence, not semantic changes or cognition.
- Judgments may be unchanged despite a new version; absent notes are not absent beliefs.
- Nonmeasurement committed actions include preparation; an opportunity is not proof of a new discriminating test.
- Exact repeated command sequences include container identifiers and are conservative descriptions, not verified controlled replication.
- Nominal additions are not effective concentration, dissolved inventory or post-treatment volume.
- Fixed-world sessions have uncontrolled model RNG and nested, dependent batches.
- MisIndexed was run later; between-arm path differences are descriptive, not causal.
- Recovery instructions and observations differ; no clean recovery-understanding claim.
- Independent semantic case review remains outstanding.
