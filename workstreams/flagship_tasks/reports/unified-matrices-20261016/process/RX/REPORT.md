# RX：自主实验怎样形成、限定并使用解释

RX 90场已全部完成过程精读。研究者确实能够把局部观测组织为可检验预期，执行下一步对照，形成有范围的关系并将其用于后续判断；同一段研究也可能在另一响应、操作规则或适用范围上产生没有被相应证据支持的概括。最有解释力的研究单位是**具体判断及其经历**，而不是把一次会话整体标成“理解”或“误解”。

## 覆盖与证据地位

固定设计为五世界×两目标×三信息条件×三次新会话，共90场。各场均完成12批源研究，合计1,080次源终检。全部293版笔记、7,917条公开动作、877次HPLC及所有可得封存输出均已逐场阅读；491条引文与指定版本、公开游标或题号相符。动作中7,898次提交、18次回滚、1次验证拒绝全部保留。机器核验见[精读摘要](reading-summary.json)，逐场全文见其90个链接。

269份可得封存payload中，268份通过协议验证。W01第三重复优化／MisIndexed的Q含非法负下界，虽可阅读，仍是无效答卷；W04第二重复发现／Opaque的Q因工具预算超限没有payload，不以K2的泛化讨论补造预测。其余88份Q各有12题，评价指标按每题五次参考观测均值计算。源研究完整与后测有效不能混为一个完成分母。

本报告整合各分析智能体的逐场阅读；不是独立人类复核，也不把选出的解释链计作反绎成功率。K1在源实验后封存，Q要求新条件预测，K2随后反思但没有Q真值反馈。评价者推荐复测不能回填为参与者当时已知的确认。各分组阅读文档记录其完成时的局部进度，当前整体状态以此报告及机器摘要为准。

## 1. 解释能够先于检验出现，并组织真正的下一实验

[W01第一重复发现／Opaque](readings/repeat-01/RX-W01-B12-discovery-P-Opaque.json)提供完整正向链。研究者先看到停止加热、自然冷却约44 K后仍显著转化，随后在下一批之前写出区分预期：quench后等长等待应保持约0.42转换，而非未quench等待的约0.62。下一批实际结果约0.427。这里有现象、候选解释、可区分预期、真实实验和后续采用，不依赖把终点低误差当作理解证据。其新乙腈、小体积Q的产率MAE仍为.18893；局部检验成立不保证所有定量迁移成立。

[W03第三重复发现／MisIndexed](readings/repeat-03/RX-W03-B12-discovery-P-MisIndexed.json)的中途笔记把长时过处理解释转为选择未饱和时间点的理由，再明确预告末批1650+1650 s及可反驳结果。实际转换约.873→.990、选择性约.863→.797，最终形成局部一阶近似。后来的高温Q仍误判回滚。应保留真实解释形成过程，也保留其另一判断未被验证的边界。

[W05第三重复发现／Aligned](readings/repeat-03/RX-W05-B12-discovery-P-Aligned.json)则把D长时、A热时补偿、无催化剂三个问题转为剩余批次。D长时产率下降、A加热或延时补偿、无催化剂仍耗料但几乎无目标产物，分别约束不同解释。不能将三项检验合并成已经唯一恢复微观反应网络。

## 2. 研究可以自然修订方向，也可以明确承认尚未找到预期现象

[W04第一重复优化／MisIndexed](readings/repeat-01/RX-W04-B12-optimization-P-MisIndexed.json)在两个匹配温度批之后，就把较高温度更可靠的预期改为未获支持；随后扩展较低温度范围，最终保留380–390 K区域而非单点最优。[W05第三重复优化／MisIndexed](readings/repeat-03/RX-W05-B12-optimization-P-MisIndexed.json)也在中途明确撤回方向提示，并预告下一组时间比较，之后确实执行。它们不需要额外纠错策略才构成完整认识形成结果。

另一种正向修订是停止把预期当成发现。W02第二重复发现／Opaque、W03第三重复发现／Opaque、W04第三重复发现／Opaque和W05第二重复发现／Opaque，都在相应观察范围内保留“产率峰未定位”或“最高暴露仍增产”。选择性下降并不自动等于绝对目标物减少；初始提出内部最优，不意味着数据已经观察到最优两侧。

[W04第一重复发现／Opaque](readings/repeat-01/RX-W04-B12-discovery-P-Opaque.json)尤其说明拟合与验证的区别：三时长给出近一阶转换和选择性衰减拟合，推导约3.5 ks最优；这些方程在终末笔记出现，不能倒填为选择3600 s实验前已经提出并得到验证的预测。源产率仍随900、1800、3600 s增加。局部经验模型有内容，其峰值仍是待检验推论。

## 3. 不同证据经历支持不同的风险解释，后续使用可以逐项核对

风险涉及当前热状态、历史峰值与累计暴露等不同候选。固定温度改变时间而risk近恒，能够反对简单线性累积，却不能独自区分当前状态与历史峰值；需要冷却、quench或温序证据。

[W01第一重复优化／MisIndexed](readings/repeat-01/RX-W01-B12-optimization-P-MisIndexed.json)实际获得同温异时风险近恒，却在没有冷却判别时采用峰值解释，Q认为quench不能降低该读出。相对地，[同世界第一重复发现／Aligned](readings/repeat-01/RX-W01-B12-discovery-P-Aligned.json)明确预告匹配quench对照，观察化学近同而末态risk下降，收窄化学保护主张，并把风险关系用于Q，risk MAE .01065。

[W04第二重复发现／Aligned](readings/repeat-02/RX-W04-B12-discovery-P-Aligned.json)和[W05第二重复发现／Aligned](readings/repeat-02/RX-W05-B12-discovery-P-Aligned.json)也把同温异时近恒与quench风险下降连接起来，再用于新判断。W05后者risk MAE .03871、80%区间覆盖60/60参考读数。相反，[W05第二重复优化／Opaque](readings/repeat-02/RX-W05-B12-optimization-P-Opaque.json)源实验全部固定1800 s，却将累计暴露候选用于Q长时及温序，risk MAE .39345，同时转换MAE仅.00735。

这些是证据经历与关系使用的具体对应，尚不是自主选择某类实验的净因果效应。目标分配的整体比较可以按固定矩阵统计，但“目标→选择某对照→某种解释→预测”的中介链没有因这些个案而被完整鉴别。同一Q中的不同响应也不能相互代替。

## 4. 错误有时发生在研究经历的重建，随后才进入机制与预测

[W05第二重复发现／MisIndexed](readings/repeat-02/RX-W05-B12-discovery-P-MisIndexed.json)是最直接的实例。两个600 s heat请求均回滚，物理时间和温度推进为零；最终笔记却把该批表述为真实1200 s无反应，K1据此提出诱导或分段历史变量，Q05/Q09引用这一经历，K2继续设计区分诱导和分段效应的下一实验。

这一链应表述为**失败操作被重建为化学经历，并成为解释和新判断的依据**。不能称已发现诱导期，也不能因为最终转换MAE .08866、score MAE .03363而忽略错误前提。同期末笔记才出现该解释，因此不能再声称它已经指导后续第9–12源批次。证据只支持从终末重建到K1/Q/K2的后续采用。

该机制并非所有失败的必然结果。W02第三重复发现／Aligned、W03第二重复发现／MisIndexed、W04第二重复发现／MisIndexed均将真实短热回滚从动力学时间点中剔除。[冻结动作核对](measurement-semantics/w5-r2-discovery-misindexed-failed-heats.json)保留外层成功标记与事务回滚并存的接口事实。公开呈现可能参与误读，现有轨迹不单独识别其原因。

## 5. 有效局部研究可以与操作范围或评价函数的误用共存

[W01第一重复优化／Aligned](readings/repeat-01/RX-W01-B12-optimization-P-Aligned.json)在380 K真实重复得到接近的分数，推荐复测也支持该局部结果，却把预计风险超过.35解释为必定原子回滚，导致多题近零转换。风险标记是任务约束，实际高风险操作仍可能成功提交。这不是已经观察到的化学反应停止。

另一类是把`configure_control`的430 K范围用于`heat`，出现在多个有真实局部修订的案例中。初始参数表的控制范围、后续工具可用动作范围与实际执行层须区分；W05第三重复优化／MisIndexed的保留`agent_view`明确公开heat到470 K，足以涵盖Q的440–460 K。不能把这类错误统一包装为隐藏世界机制难以发现，也不应声称一定需要新增高温实验才能避免。核对材料见[控制配置与heat](measurement-semantics/controller-range-vs-heat.json)及[W05第三重复专题](W05_REPEAT03_READING.md)。

固定成本也产生更细的适用范围问题。[W01第三重复优化／Opaque](readings/repeat-03/RX-W01-B12-optimization-P-Opaque.json)、W04第一重复发现／Opaque、W05第二重复发现／Opaque从源数据恢复了固定截距评分式。其中源cost全为1，固定截距-.1与真实-.1×cost在该切片相同；这种局部精确拟合不能识别变成本后的关系。Q换成小尺度程序后继续使用固定截距，是局部映射的范围扩展，而不是新化学规律。见[固定成本语义核对](measurement-semantics/constant-cost-score-relation.json)。

另有评分遗漏已学风险的情况：W05第一重复优化／Aligned在Q给quench前后不同risk，却给相同score。研究者能够使用某项关系，不保证相关联的数值判断一致；平均score误差较低也不能证明所用评分关系正确。

## 6. 过程阅读本身必须遵守操作与测量语义

quench返回未更新的化学数值，不是一份新测量。[W04第一重复发现／Opaque](readings/repeat-01/RX-W04-B12-discovery-P-Opaque.json)的末笔记曾据此支持反应停止，K1/K2随后明确承认可能是缓存而收窄。该自我限定可以记录为表述修订，不能充作新实验的验证结果。

冻结quench降低温度、更新risk和时钟并停止后续化学，但本身不积分物种ODE。账面冷却秒数不是经历了一段继续反应；未quench的成功wait才会继续演化并自然冷却。因而立即quench与长时间被动冷却的差异，是完整停止历史的差异，不能单独估计独立于温度的化学淬灭效应。[实现语义核对](measurement-semantics/quench-time-not-chemical-exposure.json)与逐场操作共同支持这一界定。

HPLC即时取样0.0002 L，终检取样0.0003 L；前者在5 mL研究中占4%，80 mL中占0.25%。HPLC后续热段与未取样的Q程序并非严格同一经历。HPLC和终检观测同类指标但噪声不同，差值既不能自动当化学演化，也不能自动当固定仪器标定偏差。多个近终检HPLC并不等于有多个反应时间点。

机制候选还需满足质量关系。稳定P的纯并行生成或单纯降低生产速率可以解释Y继续增加而S下降，不能独自解释既有P绝对减少；实际跨批产率下降仍有噪声、初始差异与测量限制。列举“并行、降解、失活”不等于所有候选都同样解释数据。

## 对论文主线和补充实验的具体含义

RX证据已经能够支持：自主研究如何选择证据、形成局部解释、据此检验、限定关系，并在另一用途上扩展或重建失当。无需把全部材料统一为自我确认循环，也不需要让每条过程都以纠错干预成功结尾。主文可以用一条具有完整同期链的正向案例，与一条错误经历重建链并置，再用风险关系、操作范围及固定成本关系说明迁移为什么需要按具体认识区分。

当前90场的过程分析本身已经完成，**为这项描述性与过程性主张不必再补一个全覆盖矩阵**。如果需要更强因果措辞，追加实验应对应明确的新问题：

| 希望新增的结论 | 最小需要的对照 | 当前材料尚未证明的部分 |
| --- | --- | --- |
| 失败动作的呈现方式导致虚假化学经历 | 同一保留轨迹、相同信息量，随机改变状态呈现清晰度，再封存解释和新预测；不告诉标准机制 | 现有案例定位了重建错误，未分离界面呈现、注意和记忆组织的原因 |
| 获得特定风险证据改变了状态量理解 | 匹配研究预算和其他经历，对比能／不能区分峰值与末态的观察，再看相同风险及化学后测 | 当前自主选择对照与后续成功相关，不是该观察的独立净效应 |
| 精确恢复了晚期目标损失或唯一反应拓扑 | 有重复的同仪器时间记录、取样匹配及可区分候选的操作，按源实际允许观测设计 | 现有局部峰与后期下降尚不识别唯一P→D或催化失活 |
| 反绎型组织策略普遍优于其他策略 | 预先固定策略差异、资源及覆盖，并分别测解释内容、判别行动和迁移 | 本轮不是策略优化试验，不能由选例给成功率或普遍优越性 |

这些是条件性的下一问题，不是完成现有主线的必选套餐。任何新数据块应另有简短固定设计说明；不覆盖、替换或回填本轮不利结果。
