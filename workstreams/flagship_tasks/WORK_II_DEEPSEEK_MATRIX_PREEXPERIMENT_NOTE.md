Date: 2026-08-11
Status: frozen before new provider execution

## Question and coverage

Can the current DeepSeek Codex-compatible harness execute the newly admitted parametric
initial-world-model intervention while preserving the same persistent-session, operation-level,
resource-ledger, checkpoint and evaluator semantics used by the Work II matrix?

- Existing A-E coverage is reused, not rerun: five tasks × five seeds × three arms = 75 retained
  DeepSeek development cells, with the existing provider-free evaluator report.
- The only new provider-producing block is A-P electrochemical D1 at `public-test`, `world_seed=1`:
  `opaque`, `aligned_nominal` and `misindexed_nominal` use three fresh DeepSeek sessions.
- Each cell contains four complete experiments, four typed checkpoints and one shared campaign
  resource ledger: 3 cells, 12 experiments and 12 checkpoints total.
- A-S is not provider-admitted because the current structural candidate failed its environment gate.
  B and D are not executable because their separate contracts are not frozen.
- This block is development evidence only and is excluded from every formal denominator.

## Measurements

- terminal/completed cells, experiments, checkpoints and operation attempts;
- validation failures, resource rejections, MCP recoveries and provider errors;
- input, cached input, uncached input, output, wall time and liveness;
- participant prediction error, initial-model reliability, challenged fields, executable-law error
  and final recommendation;
- four evaluator-held truth queries and 18 paired blind replays, all with zero evaluator provider
  calls and exact replay.

## Pass and failure rules

- Operational D1 pass requires 3/3 terminal qualified cells, 12/12 complete experiments, 12/12 valid
  checkpoints, exact physical/resource replay, no hidden arm leakage, and limits no weaker than:
  three recovered MCP failures, one consecutive MCP failure, one provider-error event and one resource
  rejection per cell.
- Scientific direction is never an admission rule. Prior rejection, persistence, no effect and harmful
  correction are all retained outcomes.
- A scientific trajectory is never replaced. Only a missing-infrastructure-only failure before any
  persisted scientific operation may use the existing single-resume rule.
- If all three arms fail before the first committed operation, stop the block as a systemic harness
  failure. Otherwise retain each cell and complete the scheduled triplet.
