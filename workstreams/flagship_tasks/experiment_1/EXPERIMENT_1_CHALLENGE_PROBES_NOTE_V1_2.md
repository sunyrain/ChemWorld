# Experiment 1 executable challenge probes v1.2

Status: **frozen design before attempt 3**.

This campaign is a development challenge, not confirmation. It reads the existing
50 public qualification evidence bundles for the ten five-World loci and preserves
every denominator and failure. It does not generate or consume confirmation secret
material.

## Frozen estimands

- The default action and ordered legal actions are fixed per locus in the v1.2
  contract and do not inspect private truth, arm assignment, or realized outcomes.
- A participant trace observes one hidden law family only. Where both law-family
  receipts exist for development qualification, the paired result is retained only
  as an explicitly labelled offline separability estimate; it is not placed in the
  participant observation digest and cannot choose the next action.
- A reliable stop requires the preregistered evidence threshold and repeated-noise
  support derived from distinct receipt noise coordinates. No repeat count is
  supplied by configuration.
- Active-information evidence is the declared evidence-statistic gain at the first
  reliable stop relative to the fixed default action. Later actions cannot rescue a
  failed stopping step.
- PA-P predictions and measurements are recomputed from public prior bands, volumes,
  and raw receipt measurements. EC-S candidate errors and prediction differences are
  recomputed from raw main-grid and noisy-validation rows using the frozen model
  feature maps. Precomputed qualification pass fields are not consumed.

## Fail-closed provenance

The runner must load the exact registry path bound by the contract, verify its file
digest and canonical self-hash, verify the raw-evidence manifest file digest and
canonical self-hash, and verify every report file against both the registry evidence
binding and manifest report digest. Missing, malformed, duplicated, stale, or
digest-mismatched evidence is a completed denominator failure, never a silent skip.
The audit independently recomputes the registry, manifest, probe, and audit
self-hashes.

## Execution rule

Attempt 3 starts from unit zero after this note, contract, runner, and tests are
committed. A locus passes only when all five World rows complete and all four
challenge checks pass. Blocked loci remain visible and do not prevent independent
locus-wise decisions, but no result from this campaign is confirmation evidence.
