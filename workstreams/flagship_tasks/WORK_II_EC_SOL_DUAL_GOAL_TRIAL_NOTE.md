# EC 十二批三臂开发试跑

日期：2026-09-18；W2-122。用户授权单世界试跑，模型固定 GPT-5.6 Sol / medium。
这是 development 数据，不是正式 benchmark，不重建旧资格或发布审计。

- 问题：同一 EC 世界中，O/A/M 先验如何影响自由取证、最终机理解释、未见条件预测和操作选择；探索与优化目标是否改变这些行为。
- 固定单位：EC-W01（注册顺序首个世界），机理探索/体系内优化 × E/P/S 三个分别干预的先验层 × Opaque/Aligned/MisIndexed，共 18 个独立来源会话，每条件一次；共享世界，独立机制样本量为 1。
- 资源：每场 12 个完整实验位、12 次中途仪器测量、12 次终检（另计）；允许重复、分段操作、自由选条件。360 次操作上限、充足原料（0.48 mol reagent / 0.96 L solvent）、144000 s 过程时间。测量预算为上限，不强制用满。没有预设实验序列、强制机制候选或中途结构化规律快照。
- 目标：探索组以形成并检验可解释和可预测的世界规律为首要目标；优化组以公开 balanced-efficiency-v2 得分为首要目标。两组均提交一个已完成批次作为可复测的操作建议；探索组该建议只是辅助读出。公开仪器、评分和安全语义一致，current_mA 是电流幅值上限。
- 先验：E 沿用已登记 EC-W01 E0/E3 描述交换；P 沿用当前资格的局部方向主张及参考上下文；S 沿用电流/传质结构主张与登记参考上下文。只改变被操纵的信息；不向 participant 显示臂名、种子、后台定律或资格结论。
- 顺序：来源 12 批并封存建议 → K1 自由机理报告 → Q 十二个预先固定条件的盲预测（6 个连续指标及 80% 区间）→ K2 深入复盘。每步独立封存，同一来源 thread 续接；K1 前不展示具体预测题，所有预测完成前不反馈真值。
- K1 问完整机理、依据、适用范围、未确定因素，允许自然语言/方程/伪代码，不限定模型形式。Q 问产率、选择性、法拉第/传质/能量效率和公开得分；K2 问先验哪些支持/反驳/未检验、关键证据、竞争解释、最有价值的下一实验、可能改变判断的结果、探索与优化冲突及信息损失。自述不等于独立证明。
- 评价：逐批资源/操作/观测、终检数、回滚/工具/提供方失败、建议复测、精确重放；预测 MAE、区间覆盖及宽度分指标报告，不与机理文字混为总分。机理先做逐证据可核查分析；本轮不新增未经校准的 LLM judge 分数。不要求 Agent 失败，也不以预测好坏决定补跑。
- 固定额外物理单位：1 场无 provider 的 12 批工程连通检查；12 个盲预测参考条件各执行一次并 exact replay；每个有合法建议的来源独立噪声复测 1 次（最多 18），均单列，不算来源样本。参考结果不送回来源。
- 停止/失败：每来源墙钟上限 90 分钟，每后测 20 分钟；无自动 provider 重试，无科学质量补跑。单来源失败保留并继续计划单元；共享平台故障停止后续来源，修复后按新修订块重新开始受影响块，保留旧尝试。下游不可用仍保留 18 的分母。掉线/中断不得冒充完整结果。
- 输出：ignored runs 中完整 prompts、provider 轨迹、物理轨迹、replay、用量与逐场结果；Git 中保存可读机器摘要和中文报告，含所有实际问题、回答、失败和分母。运行每 30 秒报告阶段、批数、事件数及已完成会话；ETA 用实际吞吐更新。

本轮三臂和两目标独立会话，不强行把 12 批分成探索/优化各 6 批；后测不消耗这 12 批名额。

## 启动故障记录

v1 的无 provider 工程检查 12/12 批及 12 个预测参考均通过。来源启动发生共享接入故障：
8 场在首动作前退出，另 1 场在停止队列时中断；均无实验操作、无已观察到的 usage。
这不等于证明没有任何后台计费。原目录完整保留，不算科学阴性结果。
修复块沿用同一设计，增加 stderr/stdout 保留和首动作前故障立即停队列；不按 Agent 表现更换设计。
无物理语义改变时直接复用明确标记的工程/盲测参考，来源受影响块从第一单元重新开始。

v2 首场立即停止并捕获具体原因：旧 public_numerics CLI 拒绝来源的 128 次计算额度（旧工具硬上限 8），
导致 MCP 握手失败，尚未启动模型 thread。修复为可显式设置 1–256 次，默认仍 8；
本轮来源 128、每个后测 8 次公开计算，不读取后台数据。v3 重启来源块，原 v1/v2 故障均保留。

v3 首场已启动模型并读取资料，但首动作进入物理执行前，接入层遗漏 method_resource_limits，
无法登记长会话的延迟 token 用量，因而停块（0 个物理操作）。v4 显式传递单会话/墙钟/宽裕 token
上限，保留正常资源记账，不绕过记账检查。无科学输出选择，物理与问题设计未改变；该失败另列。

v4 来源已完成十二批并 exact replay。K1 的新进程在加载配置阶段失败（未进入模型 turn）：
disabled 的 lab MCP 仍需合法 transport 配置。后测修复仅补充 disabled server 的 command，
