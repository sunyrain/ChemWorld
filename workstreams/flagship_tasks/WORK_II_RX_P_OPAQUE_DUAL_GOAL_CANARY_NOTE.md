# RX-P Opaque 双目标开发 canary

日期：2026-09-18。用户授权先运行一个 RX 先验臂，并在相同隐藏世界上分别完成机理探索与安全约束优化。模型固定为 GPT-5.6 Sol / medium；这是 development 数据，不是正式 benchmark 或多世界结论。

- 问题：在同一 RX 反应—热过程世界和相同资源下，机理探索与安全约束优化两种委托是否都能完成自主十二批研究、封存交付、自由机理报告、预注册盲预测与复盘全链。
- 固定单位：`RX-W01`，P（局部温度—时长规律）层，Opaque 臂；机理探索和安全约束优化为两个独立来源会话，不共享实验结果。Opaque 不提供该局部方向规律，但保留与 A/M 相同的参考上下文和公开合同。本 canary 不启动 Aligned 或 MisIndexed。
- 物理底座：使用已资格化 P 层所在的 `reaction-safety-constrained` / `catalyst_deactivation` 世界，seed 0；不把另一 `reaction-mechanism-explanation` / `autocatalytic_reaction` 场景的证据混入本块。
- 资源：每来源最多12个完整批次、12次非终检仪器测量、12次终检、360次操作尝试；原料0.48 mol、溶剂0.96 L、催化剂0.06 mol、过程时间144000 s，每次quench事前保守120 s并计入该上限。重复、分段加热/等待、取样和淬灭均可自主选择。安全回滚和未完成批次保留。
- 任务：探索来源以解释目标生成、竞争转化、催化剂作用/失活、实际热历史与终止时机为首要目标；优化来源以安全限制内的公开 safe score 为首要目标。两者均从已完成批次封存一个可重放操作建议；探索建议只作辅助读出。
- 封存顺序：来源实验与建议 → K1自由机理报告 → Q十二条事前固定温度—时长条件的定量盲预测 → K2三问复盘。K1前不展示Q；Q/K2期间禁用实验室且不反馈真值；同一来源 thread 续接。
- Q指标：yield、conversion、selectivity、byproduct signal、safety risk 和 score，各给点估计及80%区间。十二条条件从既有、结果独立冻结的 RX-W01 P 资格包中按固定顺序选取；本块不根据来源行为或得分换题。
- K2仅问：最重要的未验证/可能错误规律；一次区分竞争解释的合法实验及结果分支；未利用证据、最不可靠预测或K1/Q不一致。自述不等于独立证明。
- 评价：保留逐步轨迹、资源、回滚、实际模型可见输出、模型用量和全部失败；精确重放；盲预测逐指标MAE、80%覆盖与区间宽度；有合法建议时按来源资源语义独立复测。探索知识与优化表现分开报告，不合成未经校准的总分。
- 停止规则：每个来源只有一次 provider 进程机会，无自动模型重试；单来源失败保留。首来源若在任何物理动作前发生共享接入失败，则停止后续来源。合法终止且已封存建议的部分来源仍执行K1/Q/K2，不因未满十二批跳过后测。不得因科学结果不理想补跑或改变问题。
- 输出：当前原始运行保存在 ignored `runs/development/work-ii-rx-p-opaque-dual-goal-canary-20260918-v4/`；Git 中只接收后续生成的可读摘要、机器摘要和本说明，不接收凭证或原始 provider 会话。预演v1在首批quench前因未声明隐式时间预留而停止，无provider调用、无完成批；v2完成工程预演和12条盲测真值，但首个正式来源在0动作/0批次时因远端缓存登录过期且该账号用量到限而停止。v3复用封存工程/真值并成功验证用户授权的新登录，但当前Codex CLI的MCP工具路由需要Code Mode host，旧EC命令显式禁用它；因此模型已响应却无实验工具，仍为0物理动作/0批次。v4仅修复当前CLI的受限MCP工具路由，继续禁用shell、浏览器、multi-agent等非实验能力；科学设计、盲测题和真值不变。

本块首先执行无 provider 的12批工程连通检查及12条盲测参考并核对 exact replay；通过后才调用两个来源。真实第一来源是预定样本，不在无设计变更时做完后丢弃重跑。

## 执行结果

正式 v4 已完成两个相互独立的来源：共 24/24 批、169 次来源动作、24 次 HPLC、24 次终检、0 次安全回滚；两份封存建议均通过 exact replay 和独立复测。探索来源选择 `420 K × 2200 s × quench`，复测 safe score 为 `0.438448`；优化来源选择 `408 K × 2300 s × no quench`，复测 safe score 为 `0.397447`。两来源的 K1 自由机理报告均完成。

v4 的原始 Q 阶段因继承的 `public_numerics --limit 8` 低于十二条盲测所需调用数而以 `tool_budget_exceeded` 失败；该失败及原始 `result.json` 保留。随后 repair-v3 只恢复同一来源 thread 和预先冻结的十二条 Q 条件，将数值工具预算修正为 128；没有新增物理实验、没有反馈真值、没有改题。两来源的 Q 与 K2 均完成。探索来源的 score MAE 为 `0.009307`、80%区间覆盖率为 `1.000`，但 safety 覆盖率仅 `0.250`；优化来源的 score MAE 为 `0.047071`、覆盖率为 `0.750`，safety 覆盖率为 `0.333`。完整逐批结果、故障链和边界见[结果报告](reports/work-ii-rx-p-opaque-dual-goal-canary-20260918/REPORT.md)。

本 canary 只证明 `RX-W01 × P × Opaque` 在两种目标下的端到端可执行性；单世界、单臂不能估计 O/A/M 臂效应，也不能把探索来源的较高分数解释为任务目标的因果优势。是否扩展 Aligned/MisIndexed 或更多世界需要另行冻结和授权。
