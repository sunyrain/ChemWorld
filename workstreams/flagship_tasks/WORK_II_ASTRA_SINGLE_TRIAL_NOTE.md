# Work II：Astra 单次开发试跑

日期：2026-09-14。用户授权：先做尝试性实验，仅 GPT-6 Astra / medium，每个实验一次。
本块为 development，不是正式资格或论文证据；不重复 seed，不补跑失败，不按结果改设计。

- **问题与范围**：先用反应—结晶的一组四格世界贯通 E1 取证、E2 组合部署、E3 同证据交付/内容干预。
  R1C1、R2C2 为学习组合，R1C2、R2C1 留出；不扩到蒸馏或其他模型。
  一次指每个预定条件一条执行链；来源链含两轮、每轮每个学习世界三个新批次，共12个取证批次。
- **世界**：共同基础世界由新开发 seed 确定，不复用旧证据。R1 为基础反应，R2 增加目标产物逆反应
  （severity 0.8、full-severity reverse rate 0.000625/s）；C1/C2 分别施加溶解度轴 extrapolation
  severity -1/+1。所有非目标字段共用，同一组件跨组合不重新抽参。公开匿名身份、流程与测量合同。
  本轮为预定构造例，未宣称常规终点匹配、总体覆盖或学习信息已充分可辨识。
- **操作与预算**：固定加溶剂/试剂/催化剂—反应—quench—可选 HPLC—播种—冷却—过滤—terminate—final assay。
  Agent 控制反应温度[350,405]K、时间[1200,5400]s、冷却温度[275,310]K、时间[1200,7200]s，
  以及是否做中间 HPLC；固定试剂0.015mol、溶剂0.025L、催化剂0.000315mol、晶种0.008g。
  每批最多12个操作；逐批完整记账。所有部署在目标反馈前封存合法完整流程，属于 E2 的开环开发子集；
  自适应操作顺序、目标批次内闭环决策和正式的同资源效用比较留待后续。
- **E0**：四世界各执行两条预定流程一次，检查生命周期、精确重放、上游不受C身份影响、下游确有响应差异。
  若运行语义或重放失败，保留全部已执行记录，依赖项标为未执行；不自动修复后重跑本块。
  科学差异不足如实报告，不换世界寻找失败。模型接入不另做有消耗的空探针，首次来源调用兼验接入。
- **E1**：标准自主来源和结构化判别来源各一次（各12批，第二轮看到第一轮证据）；相同复用目标、
  参数/测量权限、每调用8次公共算术/最小二乘工具上限。另做12批预定空间填充参照。
- **E2/E3**：每种来源各生成整流程摘要和组件知识包一次，字符总上限均3600。
  基础交付为标准/结构化来源×Raw/整流程/组件，另加task-only，共7个条件。
  以标准来源组件包为固定诊断对象，追加R身份间知识互换、C身份间知识互换、内容不变重序列化、
  公开数据R关系补充、公开数据C关系补充，共5个条件。补充只用同一来源公开记录拟合，保留其他字段。
  每个条件只开一个fresh读出会话，预测四世界各2条盲测流程并为四世界各交付一个部署流程；
  四个回答不是独立会话复现。各部署只执行一次，目标结果不返回模型。所有表示生成先于盲测坐标披露。
- **参考与测量**：固定岭回归分别拟合上游响应与下游产率关系，另有整流程岭回归及最佳历史流程参照；
  全部只用公开学习记录。小样本经验参考不冒充已资格的强系统辨识或真值上界。
  读出盲测reaction yield / crystal yield / purity误差、各世界终端score、取样/资源/失败和同记录Raw-K差值。
  暂以产率绝对差0.03作描述性实质差异提示；不作显著性、饱和、等效或系统性失效推断。
- **分母与停止**：GPT最多20个科学调用（来源4、编码4、读出12），每调用一次，timeout 600s，provider retries=0；
  全块上限4小时，串行。来源失败不替换，依赖项保留为未执行；无效表示/预测/流程分别记录。
  预计物理执行上限：E0 8、来源36、盲测8、Agent部署48，另每来源组件参考/整流程参考/历史流程各4次部署共24；
  合计124条原始轨迹，各作一次exact replay（重放不算独立实验/噪声重复）。不进行正式世界筛选或多模型复核。
- **输出**：ignored `runs/development/` 保存输入、公开证据、原始provider输出、动作、轨迹、重放、完整资源和所有失败；
  `reports/` 生成脱敏JSON与中文Markdown摘要，给计划/尝试/完成/失败/未执行分母。
  每30秒输出当前stage、已完成调用/总调用、吞吐、ETA或具体事件计数。凭据只在系统临时目录使用，不入Git。

## 开始模型调用前的工程修正

首次8条E0轨迹已结束，全部因新流程编译器遗漏过滤前必需的浆液HPLC而回滚，继而导致终止/终检失败，
runner随后耗尽动作。它们保留为工程失败，零模型调用；不改写为成功，也不据此评价Agent。
修正为“冷却—必需HPLC—过滤”，同时使runner预算等于封存动作长度；反应后HPLC仍可选。
问题、世界、参数范围、测量指标和Agent条件不变。单列执行修正后的8条E0，原始物理总计划变为132
（旧工程失败8 + 修正后原计划124），GPT上限仍20，每条件一次。此为模型实验开始前的显式编译修正，
不是科学阴性后的重试；若修正后仍失败则停止依赖项。完整Raw指规范化公开科学记录，原始谱图和轨迹另存。

## 本块终态：公开合同错误后早停

实际仅使用GPT-6 Astra / medium，10/20次模型调用完成、零模型重试，其余10次未启动。
标准/结构化取证各12批、空间填充12批，共36/36批完成；四份知识包有效。
随后发现试跑把播种前HPLC错误列为可选，同时遗漏冷却温度不得高于quench后当前温度的耦合约束。
因此4/8盲测流程失败；已启动的Raw/整流程部署受错误合同污染，定向E3未执行，停止剩余块且不替换结果。
这不是Agent未遵循正确科学知识的证据；此前8条修正后检查只验证所选必测路径，未覆盖可选测量分支。
