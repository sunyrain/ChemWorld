# Work II：修正合同后的 Astra 开发实验

2026-09-14，W2-100。用户授权修正合同并进一步实验；沿用仅 `gpt-6-astra / medium`、每条件一次。
本块重新取证，W2-99关闭且原结果不变。开发数据不自动进入论文正式证据。

- **问题**：合法操作和有意义的产物效用下，标准/结构化取证、Raw/整流程/组件交付以及单组件内容干预，
  是否改变未见组合预测与首次部署？不预设信息损失、模块化优势或Agent失效。
- **单位**：一组新随机初始化的反应—结晶四格世界；R1C1/R2C2学习，R1C2/R2C1留出。
  R2沿用已声明逆反应干预，C1/C2沿用溶解度轴-1/+1；其余参数在四格内相同，组件跨组合不重抽。
  不按效果筛选seed；不含蒸馏、独立复现或总体推断。
- **合同**：固定12步：溶剂、试剂、催化剂、反应、淬灭、必需HPLC、晶种、冷却、必需HPLC、过滤、终止、终检。
  固定物料与上一块一致。TR∈[350,405]K、tR∈[1200,5400]s、tC∈[1200,7200]s；
  冷却控制改为f∈[0,1]，TC=275+f×(min(310,max(298.15,TR−45))−275)K。
  这是公开控制坐标映射，非失败后的裁剪；提交f越界/缺字段/非有限数均原样记失败。执行核对实际淬灭温度。
  操作顺序固定、部署开环；测量仍付样品/时间/成本，不宣称完整自适应Agent能力。
- **效用**：公开定义 `quality_adjusted_recovery_estimate = HPLC_yield × (1−0.00020/0.025) ×
  terminal_crystal_yield × terminal_crystal_purity`，再以实际过程账本时间计算
  `utility_per_hour = 3600 × quality_adjusted_recovery_estimate / process_time_s`。
  晶体回收率扣除晶种；零回收的效用必为零。这是基于公开有噪观测的质量加权产物估计及生产率，
  不是精确摩尔质量测量；纯度为公开的含晶种固体纯度，不冒充新生产物纯度。原task score仅作诊断。
  全部方法目标、权限、物料及每批动作预算相同；时间成本进入效用，其他资源分列，不追溯改旧评分。
- **E0**：事前固定8条二水平正交覆盖流程×4世界=32批，覆盖四控制轴的全部两两水平组合，
  包含350K淬灭后暖端上限和极端时长。所有12步提交、终检和exact replay须通过；同R上游观测不随C变。
  检查扣种零回收效用、C响应差异及同一固定流程在四世界的效用差距，后两者不足如实报告，不能筛掉世界。
  任一运行/重放/上游不变量缺陷则结束块，不启动模型；工程修复必须另起块。
- **E1**：标准和结构化来源各2轮，每轮每学习世界4个批次，共各16批；第2轮只看本来源第1轮。
  另做每学习世界8条预定空间填充流程，共16批。三来源独立记资源；固定参考不给Agent额外证据。
  结构化来源要求控制对比与组件不确定性，标准来源可自发使用同方法；每次都可用相同8次公共数值工具。
- **E2/E3**：两来源分别生成整流程/组件知识包各一次；预算4500字符（组件5×900），编码时不披露查询坐标。
  7个基本条件：来源×Raw/整流程/组件+task-only。另以标准组件包为固定对象做R置换、C置换、内容不变重排、
  R公共数值表补充、C公共数值表补充，共5条件。置换一致重映射槽名及文本中的同族身份标签，避免自相矛盾的标签。
  补充只用同一来源已测数据替换对应槽，未改变槽保留；不用真值。
  每条件1个fresh读出会话，同时预测固定3条流程×4世界=12查询，并交付四世界各1条部署；目标结果不回传。
  不把同一次调用中的多个回答当独立重复。
- **盲查询**：按控制顺序(TR,tR,f,tC)固定为(355,2100,0.2,2400)、(382,3900,0.55,4800)、
  (400,1500,0.85,6600)；先封存所有知识包，再执行12条查询。每条一次，无失败替换。
- **参考**：每来源按公开数据拟合固定岭回归的组件/整流程参考；标准和结构化来源各3种部署参考
  （组件、整流程、最佳历史流程）×4世界=24批。所有规划使用同一81点合法控制网格；无私有真值规划器。
  小样本参考未获强辨识资格，不以其失败证明不可恢复性。
- **覆盖与解释**：预先固定基于公开测量的联合覆盖诊断：上游HPLC yield/conversion、淬灭温度、
  冷却温度和log冷却时长组成归一化5维向量；计算目标到同C来源凸包的最小L∞距离，≤0.05标为近支持。
  温度分别按55K/35K、时长按log6归一化。另报产率边际范围。参考覆盖用固定来源，实际覆盖按各Agent来源。
  这不是完整隐状态支持证明；全部事前查询保留、分别报告近支持/外推数和误差，不因模型表现移动边界。
  若支持不足，组合结果只能作为含外推的开发诊断，不能称纯组合失效。后续正式设计仍需完整接口与可辨识性资格。
- **测量**：学习/留出各6查询的反应产率、扣种晶体回收率、纯度MAE；逐世界产物估计、每小时效用、
  旧score及完整资源/失败。Raw–K同证据差和内容干预差只作描述；一次试跑不提供显著性或系统性归因。
- **分母与停止**：32 E0+48来源+12盲查询+48 Agent部署+24参考部署=164原始物理轨迹，分别exact replay。
  GPT最多20调用=4取证+4编码+12读出；仅Astra medium、provider retries=0、每调用600s，全块4小时。
  无效输出保留且不重试；缺失来源不填补依赖条件，其他独立条件继续。若合同/平台/重放缺陷出现则结束依赖块；
  一般科学阴性不早停。保留计划/尝试/成功/失败/未执行分母和中断前缀。
- **输出**：原始provider、私有初始化、轨迹及完整账本留在ignored runs/development；生成脱敏JSON/中文报告，
  绑定current；每30秒输出stage、完成/计划、吞吐与ETA。功能检查和报告核算不启动额外模型实验。

## 终态：加热设定值不等于实际温度

首条E0的12步均提交、exact replay通过，但新增温度检查失败：加热存在动态响应，初温也随世界变化。
因此不能由TR设定值推导实际淬灭温度。原始1条检查失败保留，剩余163条及20模型调用均未启动。
修正使用操作schema公开的实际当前温度；新块沿用相同世界初始化，并按
[状态解析实验说明](WORK_II_ASTRA_STATE_RESOLVED_PILOT_NOTE.md)从首条重新验证，不续跑本块。
