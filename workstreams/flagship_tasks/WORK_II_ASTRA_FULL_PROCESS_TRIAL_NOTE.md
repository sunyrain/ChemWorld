# W2-103：完整流程单轮开发试跑

2026-09-14；用户授权“现在只做一轮实验，先看看效果”。单executor，development。

**问题与覆盖。** 从固定配方转向自由操作后，Astra是否自主选择测量、调整过程并完成有质量要求的产物交付？
按固定顺序运行原生反应—纯化、反应—结晶、反应—蒸馏，均public-test、world seed 0、observation seed 1，
keyed噪声。每任务一个事前脚本参考、一个GPT-6 Astra / medium自主单批，共3参考+3受评条件，各一次。
世界使用注册实例，不按模型表现选择或改参。参考不向Agent展示；结晶参考包含过滤前复热/再冷却，蒸馏参考包含两次蒸馏。
具体参考动作在本块runner中事前固定。参考用于发现接口/记账问题及提供可达性见证，不是强优化基线。
本轮不宣称完成多批科学发现、组合留出、信息损失因果定位或正式资格，不扩大为E1—E3全矩阵。

**任务。** Agent获得完整原生操作/仪器合同、材料公开信息与动态合法操作；自己选择材料、用量、顺序、
控制、测量和过程终点，无候选表、固定步数或人工代操作。每个任务一只容器，显式终止及final assay；
新批次/重新开始不允许。纯化允许选相/洗涤/干燥/浓缩；结晶允许分段冷却、等待、复热溶解/再冷却；
蒸馏允许分段处理和累计收集。合法高效流程不强制用满这些操作。

**资源。** 单批动作上限分别90/72/72；各12次非终检仪器、1次终检；过程时间43200秒。
各批库存上限：试剂0.04 mol、溶剂0.08 L、催化剂0.005 mol、晶种0.05 g、萃取剂0.08 L、
加相液0.08 L、洗液0.08 L；仅适用操作扣费。沿用原生物理费用/采样扣除；隐式quench 120秒、
filter 480秒。每受评条件最多1个provider进程/会话，允许该会话内多轮模型响应；无provider重试或补跑。
每会话墙钟上限1800秒，单次等待上限600秒，终答等待120秒；错误动作可在原剩余预算内修正，保留错误。
独立资源账报告全部模型输入/缓存/输出token及进程/会话/工具次数，不把一个会话算成一次物理动作。

**测量与判定。** 主报告逐步动作、公开测量、合法/失败次数、终检、完整资源及精确重放。
纯化检查purity≥0.80及recovery≥0.10；结晶检查crystal_purity≥0.80、排除晶种的crystal_yield≥0.10、
crystal_fines_fraction≤0.50；蒸馏检查distillate_purity≥0.80及distillate_recovery≥0.10。
这些是本轮公开探索性质量目标，非已验证的正式阈值。Agent质量达标后追求更高回收并控制成本；
原生score及阈值达标单列，不用加权分数掩盖质量不合格或零新增产物。
若参考未达到质量目标，保留运行但标记质量可达性未获参考见证，不据此宣称Agent能力失败。
记录热/冷却/蒸馏重复、测量前后操作与不可逆动作位置；测量后采取动作不自动证明因果反馈，
单条轨迹不能证明系统性失效或“丢失了科学信息”。物理损失和信息损失分别解释。

**停止与输出。** 参考若无合法终检、出现事务失败、资源不对账或重放失败，则该任务Agent不启动，保留原因；
其他独立任务继续。Agent终检、预算耗尽、超时或provider失败即终态；无自动终止/终检、重试、换seed、补跑或替换。
任何平台缺陷保留本轮原结果，修复另立新块。每30秒报告任务、完成/总数、动作/工具计数和耗时，已完成条件提供吞吐与ETA。
原始轨迹、provider记录及私有初始化留在ignored runs；提交可读JSON/中文报告，绑定configs/current.json，更新TODO。
