# Image2 concept references for editable workflow figures

These PNGs are visual references only. They are not embedded in the manuscript,
the release SVGs, or the arXiv PDF.

- `figure-1-controlled-apparatus-image2-reference.png` preserves the four-panel
  framework layout and supplies the chemistry-native icon vocabulary used by the
  editable Figure 1 reconstruction.
- `figure-3-autonomous-lifecycle-image2-reference.png` preserves the three-panel
  autonomous-lifecycle layout and supplies the operation/instrument icon
  vocabulary used by the editable Figure 3 reconstruction.

The publication assets are regenerated by
`paper/tools/render_arxiv_release_figures.py`. Text remains SVG `<text>` and the
boxes, arrows, icons, matrices, and ledger bars are separate vector elements.
The reference PNGs are never included with SVG `<image>` elements.
