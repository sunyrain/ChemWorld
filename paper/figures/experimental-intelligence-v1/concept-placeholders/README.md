# Image-generated concept placeholders

Status: visual reference only. These six raster images were generated with the built-in
image-generation tool (GPT Image 2 path) on 2026-08-02. They are not experimental
evidence, are not inputs to any reported statistic, and must not replace the deterministic
publication figures without a separate editorial decision. Their purpose is to make the
apparatus, action sequence, resource accounting, controlled intervention and trajectory
ideas visually concrete while the final artwork is refined.

The authoritative quantitative figures are generated from
`benchmark/releases/chemworld-serious-v1/arxiv-v1-derived-data.json` by
`paper/tools/render_publication_v1_figures.py`.

## Editorial caveat

The generator introduced readable labels in some concepts despite the negative text
instruction. This is acceptable for a private composition reference but not for final
submission artwork. All final labels must be typeset deterministically, and all generated
chemical objects must be treated as symbolic rather than chemically authoritative.
