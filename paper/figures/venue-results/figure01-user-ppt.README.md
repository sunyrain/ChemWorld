retaining the original slide geometry, artwork, labels and embedded fonts.

a/b/c panel order, state that K1, Q and K2 occur sequentially without reference
feedback, and map the figure's “Mismatched information” to MisIndexed. The

figure deck. Rebuilding that deck does not overwrite this separate asset or
change the manuscript binding. No new experimental data were produced.
