# Anonymous ICLR 2027 build

This directory contains the compact anonymous review manuscript, appendix, official unmodified ICLR
assets, and the Pandoc template. The venue-neutral evidence narrative remains
`paper/prior_discovery_manuscript.md`; `submission.md` is its page-budgeted ICLR integration, not a new
scientific evidence source.

Build from the repository root with the locked environment:

```powershell
uv run --no-sync python paper/tools/build_prior_discovery_iclr.py
```

The build writes the anonymous PDF, generated TeX, and machine-readable audit to
`paper/exports/prior-discovery-iclr2027/`. The supplementary archive is rebuilt from current evidence
before the PDF is exported. Review mode must remain anonymous, with `\iclrfinalcopy` disabled.
The builder verifies the imported official assets, page count,
citations, cross-references, LaTeX errors, horizontal and vertical overflow, and a fixed set of direct
identity leaks.

The figure bundle contains ten manuscript assets. The compact manuscript selects nine (1 and 3--10)
across its main text and appendix, covering four conversion questions, historical diagnostics,
the fixed-evidence factorial intervention and independent knowledge utility. Historical qualification
details remain in the appendix and supplement.

The build includes the original 120-session disclosure intervention and its separately recorded
one-retry sensitivity, with the historical interface/tool diagnostic in the appendix.
Current page counts and completed visual QA are recorded only in the
[submission checklist](../ICLR_2027_SUBMISSION_CHECKLIST.md).
The standalone supplement verifier recomputes the four-condition
contrasts and C2/B3 failure-aware denominators, B2 expression coding, 12 M1/M3/final-diagnostic
intervals, the new ten-world disclosure interval and 24 public-packet descriptive summaries.
Selected retry outcomes and costs remain separate. Exact package contents are generated by the
builder. All bibliography records have been
resolved against source metadata. Author order, OpenReview profiles and reciprocal-review eligibility
remain manual pre-submission checks.
