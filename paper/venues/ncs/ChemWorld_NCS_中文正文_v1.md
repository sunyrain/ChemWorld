# 受控化学世界揭示自主科学研究中的泛化边界

**英文题目建议：** *Controlled chemical worlds reveal limits of generalization in autonomous scientific research*

## 摘要

自主科学研究的目标不应止于找到一个有效实验条件，还应形成能够迁移到新干预条件的知识。评价这一能力并不容易：在真实实验中，底层机制往往未知，研究者会自主选择证据，而先验信息又会反过来影响实验选择，因此一次成功或失败的预测很难被进一步分解为取证不足、不可辨识，还是对已有证据作出了不当外推。我们提出 ChemWorld，一个可编程、可重放的化学研究环境，将私有过程规律、公开实验接口、实验观测与外部信息分离，并在持久物理状态、有限资源和可验证操作约束下允许自主 agent 自由设计实验。我们在六类化学体系、八个研究块中完成 240 场自主研究，对操作交付、未知条件预测和不确定性进行分离评价。结果表明，任务成功并不保证科学泛化：在电化学中，优化任务相较探索任务使独立复测推荐在 30 组匹配比较中的 26 组改善，但得分预测仅在 14 组改善。增加研究资源能够显著改善电化学和相分配预测，却不能统一消除结晶中的响应特异性误差。先验信息的作用同样依赖响应区间：在水相平衡中，Aligned 信息改善九个问题上的预测，却在三个最稀条件下于全部五个世界中反转，并伴随区间覆盖率从约 91% 降至 2.2%。相反，在结晶任务中，纯度在来源实验和留出条件间近乎稳定，但 agent 却系统性地预测其下降；一个仅保持来源观测均值的参考在 30/30 场纯度预测中优于 agent，而 agent 在回收率上又在 26/30 场优于同一参考。两类互补现象表明，科学泛化的关键并非是否“外推”，而是能否依据证据判断一个经验关系在新干预下应当保持还是修订。ChemWorld 因而提供了一种研究自主科学推理的受控实验仪器，并提示未来评价需要同时测量操作成功、关系适用域与与证据相称的不确定性。

**关键词：** 自主科学；科学泛化；计算化学；实验设计；语言模型 agent；适用域

# 引言

自主实验室与语言模型 agent 正在把科学问题、实验规划、工具调用与可执行实验连接成连续流程 [1–3]。这类系统最直观的评价方式，是考察它是否找到一个更高产率、更高得分或更满足约束的实验条件。然而，科学研究的要求并不止于“找到一个好条件”。一个优化器只需发现一个局部高性能区域，就可能完成给定任务；而一个自主科学家还需要从有限观测中形成可迁移的关系，并判断这些关系在材料、操作历史或实验区间发生变化时是否仍然成立。换言之，操作成功与科学理解有关，但二者不能被默认等同。真正的泛化要求研究者知道：现有证据支持了什么，哪些竞争解释仍然可能成立，以及一个经验关系在什么条件下可能失效。

这一问题在真实实验室中很难被干净地研究。首先，底层物理机制通常并不完全已知，研究结果很难与一个可访问的“真值规律”逐项比对；其次，实验研究具有路径依赖，采样、分离、热处理和资源消耗会改变后续可执行实验，很难在完全一致的初始状态下重复两条自主研究轨迹；再次，先验信息不仅影响最终解释，也会改变 agent 选择哪些实验，因此预测失败可能来自缺少关键实验、证据本身无法区分不同模型，或者在已有证据下选择了不恰当的外推方式。反过来，一个预测正确的 agent 也可能只是在适当区域沿用了简单稳定关系，而并未恢复唯一的底层机制。仅依赖最终任务得分、预测误差或一段看起来合理的自然语言解释，均不足以区分这些情况。

现有化学优化 benchmark 提供了可重复的目标函数 [4,5]，交互式化学环境和科学发现环境进一步支持多步实验、工具调用和假设更新 [6–8]。我们关注的是一个互补问题：能否把“自主科学研究本身”变成可操纵、可重放和可证伪的实验对象。为此，我们构建 ChemWorld。它由可组合的化学过程规律、持久物理状态、公开实验接口和任务评价合同组成；agent 可以自由选择条件、重复实验和测量分配，却无法读取私有参数、模拟器源码或评价器真值。评价者则可以在保持公开接口不变的情况下改变底层世界，或在保持物理世界不变的情况下改变提供给 agent 的信息。由此，ChemWorld 并非试图替代真实湿实验，而是提供一种在现实中难以获得的反事实控制：同一物理世界可以被不同信息条件研究，完整实验历史可以被精确重放，操作交付、未知条件预测与不确定性也可以被分别评价。

在本文中，我们将这一框架用于六类化学体系：电化学转化、相分配、反应与热过程、水相平衡、结晶和纯化，共形成八个研究块和 240 场自主研究。所有研究均保留 agent 自主实验选择与自由形式科学解释；在研究结束后，我们封存操作推荐，并在需要时进行独立复测，同时要求 agent 对固定的未知干预条件给出点预测和区间，再进行事后证据反思。结果显示，当前 agent 能够在部分体系中通过更多证据或有用先验获得明显更好的预测，因此本文观察到的困难并非普遍的“不会学习”。更关键的是两类方向相反的错误：在水相平衡中，agent 将来源区间内成立的平台关系延伸到了应当发生转折的极稀区间；在结晶中，agent 又放弃了在留出条件下仍然稳定的纯度关系。二者共同指向一个比“能否拟合”更基础的问题：自主科学泛化要求对**关系的适用域**进行判断，即依据获得的证据决定一个关系在新干预下应当保持、修订到何种程度，以及相应的不确定性应如何变化。

# 结果

## ChemWorld 将自主科学研究转化为可控的实验对象

ChemWorld 的核心设计不是给 agent 提供一个静态输入—输出任务，而是构造一个具有持久物理后果的可执行研究世界。每个世界由公开实验合同与私有过程参数共同定义；过程组件声明状态、参数域、依赖关系与兼容接口，再由操作模型和观测模型编译成可调用的实验环境。agent 能够通过公开接口执行加料、热处理、分相、结晶、分离、采样和分析等操作，但不能直接访问私有参数、隐藏状态、评价器记录或仓库实现。实验不是无代价的查询：采样会消耗材料，分离会改变物料所在位置，热过程留下历史，操作占用时间与资源。一次研究因此是一个连续的“行动—物理变化—观测—再决策”过程，而不是一组互相独立的函数调用。

本文将自主研究过程划分为三个相互关联的阶段。首先，agent 接收科学任务和公开信息，在有限研究资源下自主选择实验条件、重复次数、测量分配和实验分组，并根据返回结果调整后续策略。其次，所有已执行操作与公开观测被保留为完整 evidence history；对于需要交付方案的任务，完成批次中的推荐在后续科学报告前被封存。最后，评价被拆分为两个出口：一条针对操作交付，将封存推荐在同一世界中用不同观测种子独立复测；另一条针对科学泛化，要求 agent 给出自由形式科学解释（K1），随后在无额外实验与目标反馈的情况下预测 12 个固定新条件并给出区间（Q），最后回答关于证据、替代解释、局限和判别实验的问题（K2）。Q 保留原始研究上下文，因此这里评价的是同一研究过程产生的可用知识，而不是仅把 K1 当作唯一信息通道的“报告压缩”实验。

为了研究外部信息如何改变完整研究过程，我们在每个研究块中设置三种信息条件。Opaque 提供可用的实验合同和匿名实体，但不提供该测试实例的特定 dossier；Aligned 增加与目标实体、有效参数或结构关系相匹配的局部名义信息；MisIndexed 则按照预先固定的方式进行错配或重新索引，而非提供任意随机错误文本。三臂共享相同的物理世界、操作空间、资源合同和未知问题，因此信息差异可以在匹配物理背景下比较。对于电化学、相分配和结晶，我们还设置 12 与 24 批次的独立研究会话；较大预算同时伴随更大的操作与计算资源，因此它表示完整 research envelope 的变化，而不是在同一条轨迹上简单追加 12 个观测。

整个研究包含 240 场计划 campaign。所有 720 个 K1/Q/K2 阶段均完成，电化学、反应过程、结晶和纯化中的 165 次计划推荐复测全部完成，来源终检为 3,597/3,600。两条来源轨迹未达到其终检预算：一条结晶轨迹在溶剂耗尽后只有 11 次终检，一条纯化轨迹启动 12 个容器但合法丢弃两个，仅留下 10 次终检。二者均保留在结果中并标记协议状态，不以更有利的重跑替换。

## 可组合基础设施分离物理规律、交互运行时与评价合同

ChemWorld 的基础设施进一步将“发生什么”“agent 能做什么”和“如何评价”分离。物理因果层负责类型化状态、可执行过程规律、仪器模型、约束和可控 world shift；实验交互运行时负责操作验证、事务提交、测量、生命周期、资源账本和轨迹记录；任务与评价合同则规定公开目标、允许的信息与动作、预算、终止条件、评价指标和场景分布。agent 本身、模型权重和私有记忆位于这三层之外，使同一环境能够由语言模型 agent、经典优化器、强化学习方法或人类通过共同接口使用。这样的分层避免把 agent 策略、物理模型和评价器写进同一个不可拆分的 benchmark 实现中。

持久状态是这一基础设施区别于静态 benchmark 的关键。候选状态转移必须在提交前通过操作合法性、物料与资源约束检查；合法操作提交后改变世界状态，非法或被拒绝的动作不修改已提交物理状态，但其约定的尝试成本与资源后果仍被记录。环境 replay 重新执行并验证世界状态与已执行操作，而不是尝试重生语言模型文本。这使研究轨迹可以在 agent 结束后被独立审计，也使任务得分不能由 agent 自报，而必须由评价器依据重放后的结果重新计算。

我们将平台内部资格验证与 agent 科学表现严格区分。冻结的平台资格验证覆盖 64 个 task–world 单元、1,786 个边界和分类配方、192 个非法动作探针与 52 个生成组合；其中 52 个生成案例包括 18 个既有参考注册表之外的拓扑、8 个在已注册拓扑上的新 task–world 身份以及 26 个额外覆盖案例。组件和接口检查另覆盖 32 个模块探针、7 条合法接口路径与 7 个非法组合。这些检查建立的是声明域内的执行一致性、资源守恒、信息分离与精确重放，不构成任意真实化学体系的湿实验验证，也不应被计作 240 场自主研究的一部分。

平台层面还允许在相同公开接口下改变私有物理规律；本文 240 场主研究则主要使用互补的控制方式——保持物理世界不变，只改变公开信息。二者共同说明 ChemWorld 的角色不是“生成一个答案”，而是提供可以操纵自主科学推理条件的研究仪器。后续结果均建立在这一边界之上：平台资格保证当前合同可执行与可重放，但并不预先保证 agent 会选择有判别力的实验、形成正确的科学关系或在未知干预下正确泛化。

## 操作成功并不意味着获得了更好的预测知识

我们首先检验最直接的问题：当研究任务明确要求 agent 寻找更高性能的操作条件时，更好的操作交付是否同时意味着对世界获得了更好的可迁移知识。电化学提供了最清晰的匹配比较。对于相同世界、信息臂与批次预算，我们将 optimization commission 与 discovery commission 成对比较。优化任务在 30 组配对中的 26 组提高了独立复测推荐得分，但对应的公共得分预测误差只在 14 组改善；其中 13 组出现“推荐复测更好而预测更差”的不一致，并分布于全部五个世界。将比较限制为双方均无基础设施驱动来源重启的 17 组，仍有 15 组推荐改善、8 组预测改善和 7 组不一致。因此，主要分离现象不能简单归因于保留的重启不对称。

这一结果并不表示优化目标普遍损害理解。反应与热过程提供了重要边界：optimization 相对 discovery 仅在 30 组中的 9 组改善独立复测，在 8 组改善公共得分预测，在原始六响应宏平均端点上则只有 6 组改善。换言之，优化指令本身甚至不是“找到更好操作”的可靠预言机，更不能被解释为一个稳定的操作—知识权衡。这里比较的是两套完整自主研究策略的结果，目标改变会同时影响实验选择与后续解释，因此我们不把差异进一步归因于某一个单独中介过程。

纯化任务从另一个角度说明了单一操作指标的不足。Aligned 条件下 5 个世界中的 3 个推荐满足纯度阈值，而 Opaque 与 MisIndexed 均为 0/5；然而三者平均原投料回收率分别为 0.04455、0.12373 和 0.32105。也就是说，更高的回收并不等于完成了“在纯度约束下回收产品”的任务。一次 Opaque 复测的纯度为 0.7992，接近 0.80 阈值，也说明基于单次带噪复测的二元合格数不应被解释成精确可靠性估计。综合这些结果，操作交付、未知条件预测以及约束满足应被视为自主科学表现的不同端点，而不是由一个统一“成功分数”替代。

## 更多实验能够改善泛化，但作用具有选择性

一种自然解释是，较差的未知条件预测只是因为 agent 获得的实验太少。12 与 24 批次条件提供了对这一解释的直接检验。电化学中，discovery 的公共得分 MAE 从 0.17378 降至 0.11222，optimization 从 0.17811 降至 0.10818；相应 15 组匹配 campaign 中分别有 11 组和 12 组改善。更重要的是，六个电化学响应的平均预测误差均随较大 research envelope 下降，且逐一剔除任意一个世界后，平均改善方向仍然保持。有限预算下的预测失败因此不能被简单归结为“推理本身有问题”；至少在这一体系中，额外研究资源能产生可测量的知识收益。

相分配提供了更强的正面例子。有机相产物分数的 MAE 从 0.08291 降至 0.02379，15 组配对中有 13 组改善；两道过程选择题的正确数从 25/30 提升至 30/30。名义 90% 区间的经验覆盖率由 78.3% 上升至 98.9%，同时平均区间宽度从 0.25122 缩窄至 0.18553。覆盖率高于名义值不意味着完美校准，但“误差下降、区间变窄、覆盖率上升”的组合说明更多实验确实可以转化为更有效的预测知识。在一个回顾性选取的 Aligned 正面案例中，24 批次会话覆盖了全部 16 种材料配对，再将 8 个实验用于过程变化，而 12 批次会话只覆盖 10 种材料配对；这一轨迹为改善提供了一个可能路径，但由于是按结果选取的案例，我们不把它当作 cohort-level 因果解释。事实上，另外两个 Aligned 世界的配对反而变差。

结晶再次显示资源效应的选择性。平均净回收预测 MAE 从 0.10433 降至 0.07937，但质量合格推荐在两个预算下都保持为 12/15，平均复测回收反而从 0.42054 降至 0.39939。细粉分数的 80% 名义区间覆盖率从 35.6% 提升到 43.9%，却在全部 30 场 campaign 中仍低于名义水平。粒径误差的微小平均改善在排除包含非合规来源的预算配对后还会改变方向。换言之，更大的研究资源确实能修复一部分预测，但不会同步改善所有响应、所有不确定性指标或最终交付。

这些结果进一步提示，研究资源不应只用“实验数量”理解。真正影响科学泛化的可能不是输入空间被采样了多少点，而是新增实验是否进入了不同响应区间、是否排除了竞争关系。相分配的正面轨迹与后文水相平衡的反例形成重要对照：更多实验有时获得了新的判别信息，有时却只是在同一响应平台内扩大输入范围。因此，我们将后续分析从“有多少数据”推进到“获得的证据是否支持把一个关系延伸到新的干预区间”。

## 先验信息的价值取决于响应区间，而非存在一个统一排序

如果更多证据不能解释所有错误，另一个自然假设是 agent 缺少合适的科学先验。反应参数研究首先表明，有用先验确实能够改善完整研究结果。discovery 条件下，Opaque、Aligned 和 MisIndexed 的宏平均 MAE 分别为 0.10186、0.05701 和 0.05457；optimization 条件下分别为 0.13893、0.08384 和 0.12967。Aligned 在两个 commission 中都于 5 个世界中的 4 个优于 Opaque。因此，后续不利结果不能被简化为“给 agent 更多正确知识总是有害”。在其他研究块中，三种信息条件却没有共同排序；相同资料的价值可以随目标、响应和未知干预区间而改变。

水相平衡参数研究展示了最清晰的区间反转。总体宏平均 MAE 为 Opaque 0.01214、Aligned 0.04314、MisIndexed 0.03928，Opaque 在五个世界中均优于两个 dossier 条件。若只看这一汇总，很容易得出“正确参数信息伤害预测”的表面结论。我们因此按公开配方浓度对原始 12 个未知问题进行事后分组。除了三个最稀问题以外的九个问题上，Aligned 将宏平均 MAE 从 Opaque 的 0.01008 降至 0.00465；在三个最稀问题上，Aligned 的 MAE 却从 Opaque 的 0.01833 升至 0.15862。这两个方向在全部五个世界中均一致。需要强调的是，其余九个问题中仍包含边界条件，因此这里不是一个预先声明的“插值对外推”二分，而是用于定位现有结果的响应区间分析。

不确定性表现出相同的区间选择性。Aligned 在其余九个问题上的覆盖率为 91.3%，但在三个最稀问题上仅为 2.2%；Opaque 分别为 90.7% 和 93.3%。三个最稀配方的名义浓度约为 \(10^{-4}\)–\(10^{-5}\) M，而全部 15 场来源研究的最低名义浓度都高于 0.018 M。来源实验中观察到的解离分数集中在约 0.06–0.09 的平台，最稀未知问题却要求离开这一响应区间。在一个选取用于说明 aggregate pattern 的世界中，Aligned 来源实验跨越约 90 倍浓度，而 Opaque 只有约 4 倍，但两者均停留在同一平台。最稀问题的真实解离分数为 0.65463；Opaque 预测 0.629，区间 [0.45, 0.80]，而 Aligned 预测 0.0804，区间 [0.053, 0.108]。因此，宽广的 input-space coverage 并不自动意味着获得了跨 response regime 的判别证据。

结晶在同一任务内部给出互补的响应级反转。12 批次时，相较 Opaque，Aligned 与 MisIndexed 都在全部五个世界中降低回收 MAE，却同时提高纯度 MAE；在双方来源均合规的比较中，这一联合方向仍为 4/4。到 24 批次，该模式分别只保留在 2/5 和 3/5 世界，说明它不是预算不变的必然权衡。更一般地，信息本身不存在脱离任务、响应和干预区间的统一价值。我们所观察到的，是完整自主研究过程在不同科学问题下对信息的条件性利用，而不是一种先验形式的全局优劣排序。

## 自主科学泛化同时存在错误保持和错误修订

水相平衡的结果说明 agent 可能把一个来源区间内稳定的关系延伸得过远，但这并不意味着自主研究只需要采取更保守的经验策略。结晶提供了方向相反的失败。对于每一场结晶 campaign，我们仅使用该 campaign 自身公开终检观测构造一个均值参考，并使用公开配方特征构造最近邻参考；二者都不获得额外来源实验，也不读取隐藏真值。agent 的净回收预测在 30 场中的 26 场优于观测均值，说明它能够在至少一个响应上从实验条件中形成比简单保持均值更有用的关系。然而，纯度预测在 30/30 场中均不如观测均值，粒径预测也在 26/30 场中不如均值。最近邻参考同样在大多数纯度和粒径 campaign 中优于 agent。该选择性结果排除了“agent 只是普遍不会使用数据”这一解释。

来源与留出条件的平均纯度都约为 0.985，而 agent 在 12 和 24 批次下的预测均值分别为 0.93544 和 0.94893。360 个纯度点预测中有 335 个低于参考真值；每个世界中 12 个留出条件的纯度平均极差仅约 0.02442。这解释了为什么一个常数参考会异常强，但常数参考的成功本身并不证明机制识别。更重要的是，agent 在同一批 campaign 的回收预测上具有明显优势，因此这里暴露的是**响应特异性的过度修订**：对一个在当前未知问题分布上仍保持稳定的经验关系，agent 引入了并未提高预测准确性的额外变化。

一个回顾性选取的极端案例进一步显示自然语言中的局限声明与数值不确定性可以脱节。该 MisIndexed campaign 的 K1 明确承认只测试了一种溶剂，不能建立可靠的溶剂排序；然而它对 12 个未知条件的纯度预测均值只有 0.86833，而参考均值为 0.98566，全部 12 个名义 80% 区间均未覆盖目标。这个案例不能用于估计该行为的总体发生率，也不能证明 agent 在心理意义上“知道自己错了”。它支持的更窄结论是：口头承认证据有限，并不自动保证这一限制被正确传播到定量预测区间。

将水相平衡与结晶并置，可以看到两类镜像错误。在 EQ 的极稀条件下，真实关系离开来源实验中的平台，agent 却继续保持该关系；在结晶纯度中，真实响应在当前测试分布内保持稳定，agent 却主动修订了它。由此，科学泛化不能被还原为“总是相信经验数据”，也不能被还原为“总是进行更积极的机制外推”。真正需要的是依据证据判断**应该修订多少**。换言之，一个自主科学家不仅要估计关系本身，还要校准该关系在新干预下的适用范围。

纯化结果为“预测不变性也是科学能力”提供了额外支持。在事后按固定 0.02 分辨率汇总的干预方向分析中，agent 对浓度变化下纯度和回收的小效应判断分别在 14/15 和 15/15 场中正确；对洗涤分段的回收小效应也有 14/15 场正确，但对同一干预的纯度小效应仅 2/15 场判断正确，13/15 场预测了可分辨变化。这些分析依赖预先固定的问题对与事后方向汇总，因此更适合作为支持性结果而非独立主结论；但它们与结晶一起说明，自主科学预测必须同时学习“什么会变”和“什么不应明显改变”。

这一系列结果最终把问题从“任务成功吗”“MAE 是否下降”推进到关系适用域的判断。一个有用的概念化方式是把真实干预相对于来源关系的偏离与 agent 预测的偏离相比较：真实变化大而 agent 修订不足，对应过度延伸；真实变化小而 agent 修订过强，对应过度修订。本文现有研究并未对全部体系建立统一连续的 revision-calibration 指标，因此我们不把这一框架当作已经完成的全局评分。它更准确地概括了 EQ 与结晶中由数据直接支持的两类互补现象，并为未来系统评价提供了可检验方向。

# 讨论

ChemWorld 的主要贡献包含两个层面。方法上，它把自主科学研究中通常纠缠在一起的底层规律、实验观测、外部信息和研究决策拆分成可操纵对象，使同一物理世界中的不同研究条件可以被匹配比较，并使完整行动—观测轨迹在研究结束后可重放、可审计。实证上，240 场研究显示，操作交付、预测泛化和与证据相称的不确定性可以明显分离。相分配和反应参数研究中的正面结果尤其重要：它们说明当前 agent 可以在部分任务中通过更多证据或有用信息形成更好的未知条件预测，因此本文不是一个“agent 普遍不会做科学”的失败合集，而是在定位一种选择性的科学泛化问题。

这一问题可以表述为**scope calibration**：研究者需要判断一个从来源实验中获得的关系，在新的干预下应保留到什么程度、又应在何处被修订。EQ 与结晶恰好给出两个方向相反的证据。如果只采取经验保守策略，结晶纯度可能表现很好，但 EQ 极稀条件会把来源平台错误延伸到新的响应区间；如果只强调机制性变化和积极外推，EQ 中某些问题可能需要这种修订，结晶纯度却会出现不必要偏离。因而不存在一个普适的“更保守”或“更机制化”规则。真正的能力链条更接近：**获得证据 → 形成关系 → 判断适用域 → 在干预下修订 → 给出预测和不确定性**。

研究预算结果进一步提示，决定科学价值的不是样本数量本身，而是新证据能否区分与未知干预相关的竞争关系。PA 中较大 research envelope 与更广材料配对覆盖和更好的预测同时出现；EQ 中 Aligned 来源虽然横跨约 90 倍输入浓度，却仍停留在同一个响应平台。由此，我们认为“input-space coverage”“response-regime coverage”和“discriminating evidence”应当被明确区分。本文的现有轨迹只为这一观点提供行为层面的正反例，还没有给全部 240 场 campaign 统一标注竞争假设与判别实验。因此，更强的因果结论需要在未来固定证据内容、只改变信息或推理条件，或前瞻性地规定能够区分候选模型的实验。

不确定性是关系适用域的另一面。EQ 的最稀问题并非只出现较大点误差，Aligned 同时给出了很窄且几乎完全失效的区间；在结晶个例中，文字报告已经承认证据不足，但数值区间仍未覆盖留出目标。这些现象提示，自主科学中的不确定性不应只反映观测噪声或已选模型内部的参数不确定性，还需要反映“当前关系是否仍适用”的模型或适用域不确定性。不过，本文并未对区间中的 aleatoric 与 epistemic 成分进行显式分解，因此我们把这一点保留为由当前结果支持的评价原则，而非已经识别的误差机制。

本文有几项重要边界。首先，主研究只使用一个 agent 配置，每个研究块有五个复用 world cluster；问题、响应、信息臂和批次并不是相互独立的统计重复，因此我们报告配对方向、效应大小、完整臂均值和影响度检查，而不把查询级观测当作独立样本进行显著性检验。其次，EQ 的极稀分组和结晶回收—纯度联合分析属于保留数据上的事后定位分析，不能被重新包装成预先注册端点。第三，信息臂同时改变 agent 获取哪些证据和如何解释证据，因此当前结果不能因果区分 acquisition 与 inference，也不能证明 prior anchoring、report compression 或任何心理机制。Q 始终保留完整来源上下文，故本文尤其不把 K1 与 Q 的差异解释成报告压缩造成的信息损失。最后，ChemWorld 的平台资格验证建立的是有限声明域中的内部一致性，而不是任意真实化学体系的外部有效性；本文没有湿实验验证，因此结论限于受控计算世界中的自主科学推理行为。

这些限制并不削弱受控世界作为研究仪器的作用，反而界定了下一步实验应当发生在哪里。未来自主科学评价不应只问“agent 是否找到一个好条件”，还应明确测量：它获得了哪些有判别力的证据；它形成的每一个响应关系在什么域内成立；它在新干预下修订了多少；以及它的不确定性是否随证据的可辨识性变化。就这一意义而言，ChemWorld 的目标不是用模拟器替代真实发现，而是建立一个可以被操纵和证伪的中间层，使**证据、关系、适用域和预测**之间的连接成为可以直接实验研究的对象。

# 方法

## 世界构建与执行

一个 ChemWorld 世界由公开实验合同 \(W_{\mathrm{pub}}\) 与私有过程参数 \(\theta\) 共同定义。兼容过程组件声明状态变量、参数域、依赖关系和接口，操作与观测模型将这些声明编译为可执行实验环境。agent 只能通过公开操作和仪器与世界交互，不能读取模拟器源码、私有参数、评价器记录或隐藏状态。操作可以消耗物料、时间、操作额度与计算资源；测量本身也可能消耗样品。

世界采用事务式状态更新。每个候选动作首先经过类型、物料、资源与操作合法性检查；合法动作产生候选转移并提交到持久状态，非法或拒绝动作保留已提交物理状态，同时按照合同记录其尝试后果。完整轨迹记录公开观测、执行动作、资源账本和状态转移。精确 replay 指重建环境和已执行操作，而不是重新生成语言模型响应。

## 平台资格验证

平台资格验证与 agent 科学表现分开。冻结资格覆盖 64 个 task–world 单元、1,786 个边界与分类配方、192 个非法动作探针和 52 个生成组合；生成组合包括 18 个既有参考注册表外拓扑、8 个在已注册拓扑上的新 task–world 身份与 26 个额外覆盖案例。组件和接口检查另包含 32 个模块探针、7 条合法路径和 7 个非法组合。资格验证检查声明域内的可执行性、资源守恒、信息分离、有效 query reference 和 replay 一致性，不作为任意真实化学的验证，也不进入 240 场 agent campaign 的分母。

## 研究单元与科学任务

当前研究由八个 study block 构成：电化学实体先验 60 场、相分配实体先验 30 场、反应与热过程的参数和结构先验共 60 场、水相平衡的实体/参数/结构先验各 15 场、结晶实体先验 30 场和纯化实体先验 15 场，共 240 场。每个 block 含五个物理世界和三种信息臂。

电化学与反应过程分别设置 discovery 和 optimization commission。电化学、相分配和结晶包含 12 与 24 批次研究资源包，其他块使用 12 批次。参数先验的 P 与纯化体系的 P 是不同概念。电化学改变材料、电位、电流上限与持续时间，optimization 使用公开的平衡效率得分；反应过程改变材料、催化剂负载和热历史；相分配研究材料、体积和过程改变下的两相分配；平衡研究量、体积、浓度、分步添加、解离和沉淀；结晶在纯度不低于 0.80、细粉分数不高于 0.50 且存在颗粒的质量约束下寻求扣除晶种质量后的回收；纯化在纯度不低于 0.80 的约束下寻求原投料回收。结晶与纯化的回收分母不同，不作直接横向合并。

## Agent 与信息条件

全部来源研究使用同一 GPT-5.6 Sol 配置与 medium reasoning effort，并在独立会话中运行。一个 block 内不同信息臂共享物理世界、操作空间、资源合同和留出问题。Opaque 保留操作接口和一般任务背景，但不提供被测实例的特定 dossier；Aligned 提供局部、名义匹配的信息，例如 EQ/P 中真实的 effective-pKa 区间，但不提供完整耦合规律；MisIndexed 按 block 的预定规则提供错配或重新索引信息，而非任意随机误导。

agent 可以自主选择条件、重复次数、测量分配与实验分组，并使用受限的公开数值工具。我们不规定固定机理模板、固定方程族或每批实验后的强制反思。批次、底层 operation、模型响应和基于新反馈作出的决策属于不同计数单位。每个 batch budget 同时允许相应数量的额外测量与最终 assay，其他材料、时间、操作和计算额度另行约束。24 批次条件为新的独立研究会话，且具有更大的执行与计算资源，因此预算比较是 research-envelope intervention。

## 封存评价与独立复测

对于需要交付操作方案的任务，来源研究结束后从已完成批次中封存推荐，并在同一世界中用不同观测种子独立执行，共有 165 次推荐复测。之后，K1 要求 agent 给出自由形式科学说明，包括关系、证据、适用范围与未解决替代解释；Q 要求其在无实验访问和目标反馈的情况下，对 12 个固定新批次条件给出点预测与区间；K2 在 Q 封存后询问证据支持、替代解释、判别实验、目标权衡、未使用证据、不确定性与局限。短版本合并为三个问题，反应与平衡使用七主题版本；EQ/P 另有 15 份结构化参数补充问答。

原始研究上下文在全部阶段均保留，因此 Q 可以同时使用来源历史与 K1，K2 则不能修改已经封存的 Q。当前设计因而不测量“仅通过报告传递知识”的性能，也不把自然语言机理正确性压缩成一个统一分数。

## 预测目标与评价指标

每个 campaign 对 12 个未知条件进行预测。对于响应 \(m\)，点预测误差定义为 12 个问题上的平均绝对误差：

\[
\mathrm{MAE}_{cm}=\frac{1}{12}\sum_{q=1}^{12}
\left|\hat y_{cqm}-y^{\mathrm{ref}}_{qm}\right|.
\]

区间覆盖率为规定参考目标落入报告区间的比例，区间宽度为平均区间跨度。相分配使用名义 90% 区间，其他当前研究块使用 80%。

不同体系采用不同参考目标。相分配和结晶的点预测针对最终 assay 前的无噪声响应；电化学和纯化使用固定 seeded observation；反应与平衡的点目标为每个条件五次参考观测的均值，而覆盖率针对单次参考观测计算。宏平均误差在指定 block 内对响应等权平均。由于物理量、归一化方式和参考目标不同，本文不构造跨体系 pooled accuracy ranking。

结晶的 public-mean 参考仅使用对应 campaign 的公开来源终检，最近邻参考额外使用公开配方特征。二者在拟合时均不访问隐藏真值。EQ 的 source-mean diagnostic 为独立的事后参考，用于说明在极稀问题中机械保持来源平台并不足够；它不是强系统辨识基线。

## 匹配比较、探索性分析与失败保留

目标比较按物理世界、信息臂、预算和先验作用层进行匹配；预算比较按世界、信息臂和目标匹配不同独立会话；信息臂比较则在同一 study block 内固定其他条件。五个世界在多个臂、目标和预算下复用，问题、响应与批次存在相关性，因此我们主要报告描述性幅度、配对方向、完整臂均值和影响度分析，而不把所有 query 当成独立重复。

EQ/P 的三个最稀问题由公开浓度事后确定，名义浓度约为 \(1.33\times10^{-4}\)、\(1.33\times10^{-5}\) 和 \(1.67\times10^{-4}\) M；按 3:9 加权后可重构原始 12 问宏平均。结晶的回收—纯度联合方向分析同样属于保留数据上的探索性分析。两者都不改变原始未知问题库，也不替换不利结果。回顾性选取的轨迹案例只用于解释 cohort-level pattern，不用于估计发生频率。

全部 240 场计划 campaign 均进入结果。一个结晶来源因溶剂耗尽只完成 11 次最终 assay；一个纯化来源启动 12 个容器后合法丢弃两个，仅完成 10 次最终 assay。二者均标记为 nonconforming 并保留。基础设施恢复保留先前尝试与资源核算。结晶 public baseline 的配方解析器曾遗漏两条 resource-denied transaction；修复后 30/30 baseline 可计算，原有 28 条结果逐项不变，且没有重新调用 agent 或 simulator。所有更正均与 agent 原始预测、独立复测和分母分开记录。
