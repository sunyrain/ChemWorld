## 论证与证据

全文的统一来自同一个研究对象：智能体如何在已有知识和目标的引导下组织实验，从观察中形成、检验与修订认识，再据此继续探索。解释性假说、经验关系、有效推断、决策标准和适用范围在这一过程中承担不同作用；证据按其实际研究作用呈现，不将全部活动归入单一推理类型，也不要求共同归因于一种失败机制。

| 小节 | 主要解释工作 | 核心材料 |
| --- | --- | --- |
| 使自主科学探索成为实验研究对象 | 实验自由、持续状态与独立参照使证据选择和判断形成可核对 | 四矩阵450场设计，300新增/150保留，完整失败分母 |
| 科学探索的组织与调整 | 目标和信息进入实验选择，判断改变下一行动；不同探索和推断路径构成不同研究经历 | 新EC/RX矩阵；纯化继续标准与库存耗尽；历史五模型证据路径 |
| 科学认识的形成与演化 | 前瞻预期进入实际检验，关系被建立、修订与使用；过程案例先于总体世界差异 | 反应等待—淬灭、极性特异性到优势、匹配世界与局部关系 |
| 自主探索中科学进展的性质与条件 | 从实验成果和关系建立推进至新条件推断；区分研究内行动与封存后预测，考察进展及未决问题如何并存 | 新结晶机会与同历史参照、不确定性、平衡区域反转及局部平台的后续使用 |

关键修订：新结晶研究使纯度和粒径判断明显改善，细粉区间评分仍恶化；同批十五场研究的源观测均值参考又在纯度、粒径上全部优于智能体，回收上则十四场由智能体更好。由此区分获取证据的收益与使用证据的质量，旧队列诊断继续独立保留。三组核心过程展开为完整轨迹，接口歧义只作有明确边界的支持证据。发现与误解可发生在同场不同判断上，不预设统一自我确认机制或纠错成功结局。[新增派生分析](inquiry_revision_analysis.md) · [七条核心历史索引](evidence/core_history_index.json)。
