## 原稿结构与新增证据

| 小节 | 保留的论证 | 新证据承担的工作 |
| --- | --- | --- |
| 使自主科学探索成为可检验的研究对象 | 持续状态、实验自主性、独立世界参照；跨体系与重复研究 | 匹配机制世界区分实验获得的物理信息与研究者赋予的解释 |
| 科学探索的自主组织与适应 | 目标、先验、不同模型的证据路径 | 候选解释提出条件性预期，并进入浓度、重复和稀释检验 |
| 科学认识在实验中的形成与演变 | 局部配方收益、插值撤回、平台外推与不同证据地位 | 错误经历重建如何产生表面异常，以及另一场如何自然撤回解释 |
| 自主探索中科学进展的性质与条件 | 先验和预算效应、研究机会比较、结晶各响应的证据使用 | 机制未决时局部关系仍可支持预测；不同实验的误差不作为改善幅度 |

开篇以磁体—导体的解释不对称引出重新构造理解前提的创造性活动，再连接反绎提出可能解释、演绎展开后果、经验检验与归纳评价。不是知识截止的“爱因斯坦测试”，不把全部实验动作视作反绎，也不把纠错干预成功设为论文结局。依据沿用已核对的Einstein (1905)与Peirce方法论研究。
