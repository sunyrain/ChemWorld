# Inquiry figure previews — 2026-10-18

W2-282 updates five main figures and Extended Data 5, 6 and 8 for **How autonomous research shapes scientific understanding**. All eight assets were generated and, where needed, corrected with the built-in ImageGen tool. The [saved prompts](prompts.json) include each selected output and correction request. The bilingual manuscript uses these workspace copies.

These are author-requested **previews**, not final numerical artwork. Numerical callouts retain the specified results; generated positions, slopes, bar lengths and plotted-mark counts are illustrative. Original 80% predictive intervals in ED 5 are distinguished from confidence intervals. Each image and its manuscript caption retain the preview label.

No experiments or evidence values changed.
