# ImageGen 临时预览

用户明确要求全部主图和扩展图直接用 ImageGen 生成并插入稿件。本目录保存内置 `image_gen.imagegen` 输出，生成提示见 `prompts.json`。

这些图用于查看布局与叙事，不能作为定量证据图；生成的点位、误差线、标签和视觉比例可能偏离实际记录。正文与补充表的数据来自保留证据。上一层的 PDF/PNG 是数据脚本生成的参考，未被替换。图 1 的反馈时序与扩展图 2 的纵轴/主体经 ImageGen 定向修正。
