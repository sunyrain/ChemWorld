# 了解适用范围

ChemWorld Bench 适合研究**预算受限、部分可观测的闭环实验决策**。它回答的是“Agent 如何实验”，
不是“现实反应一定会怎样”。如果只记住一个边界，就是：这里的材料、风险和结果都属于版本化虚拟
世界，不能直接指导真实实验。

## 当前证据支持哪些说法

- task、scenario、mechanism、observation、scoring 和 trajectory 使用版本化合同；
- Agent 只能通过公开操作、测量、成本、约束和历史记录与环境交互；
- 正式运行使用显式领域 provider，轨迹可以 digest 校验、确定性回放和指标重算；
- 经典、RL 和 LLM 方法可以进入同一实验与资源账本；
- 15 个完整实验适配器均通过死坐标检查和中点端到端执行；这证明设计可执行，不证明其余 13 个任务
  上的模型性能；
- 六任务的机理/构成律干预具有可执行、守恒和回放控制；两个确认性任务的 RC28 A1/A2/A3 环境证书
  在其冻结源码上通过，五实验受控识别 top-1 为 98.26%，在线端到端成功率为 96.57%；当前源码指纹
  已变化，因此该绑定为 stale，`benchmark_ready=false`，等待重新认证；
- 当前经典确认切片揭示了目标改善、风险控制与最小实质效应之间的冲突；
- 替代静态 S0 v1.0 已完成双任务十世界正式描述性比较：电化学 0.7150，结晶 0.5355；旧
  0.3902/0.4829 结果已撤回；
- 正确匿名材料属性 v1.1 只完成每任务前五个世界：电化学 nominal-vs-opaque 差 +0.0935，
  结晶 +0.0334，但两个配对区间都跨 0；这不是完整确认性结果。

## 哪些说法会越过证据

- 输出能够预测或指导真实反应、分离、谱图、装置设计或危险实验；
- 模型卡中的参考验证等于工业、法规或实验验证；
- 明确的运行路由等于全部物理模块达到专业模拟精度；
- Safe-GP 已通过完整四任务优越性规则；
- 单 seed SAC 开发结果代表 RL 性能或最佳 checkpoint；
- fake client、stub 或资格审计代表当前真实 LLM 性能；v1.0 的正式 provider 多世界结果可以报告，
  但不能被升级成广义 SOTA、provider 因果或样本外泛化；
- 环境 Gate A 通过等于 DeepSeek 或其他 Participant Agent 通过 Gates B–E；
- 公开世界结果证明跨机理、私有世界或现实实验泛化；
- 当前候选包是正式发表级 benchmark release。
- 15/15 设计 smoke 等于 15 个任务都已有正式算法实验或排名；
- 五个 sampled worlds、每 world 一条 LLM 轨迹，足以确认匿名材料信息价值、普适模型效应或现实
  化学泛化；
- 从六个候选经典家族中按总体盲均值选择最佳家族后，描述性区间等于预注册优越性检验。

## 如何理解模型精度

- 反应动力学是局部虚拟机制与速率律，不是数据库级反应预测；
- 物性、分配、设备和材料效应是版本化 benchmark 参数，真实名称不自动带来现实精度；
- HPLC、GC、UV–vis、IR、NMR、MS 和 final assay 是状态耦合的合成观测；
- 平衡、电化学、结晶、流动和蒸馏只在各模型卡的窄适用域内解释；
- cost/risk 是虚拟任务约束，不是采购报价、职业健康或法规指标；
- 整体任务成熟度按最弱必需模块聚合；当前 15 个任务的必需路径至少为
  `reference_validated`，但这只是各模型卡窄域内的参考验证；
- 电化学和平衡已有可执行构成律族，但主指标对自适应探索的稳定可辨识性仍未确认。

## 如何理解方法比较

评价把终点目标、任务主指标、在线 shaping、操作约束、过程成本、测量成本、有效性、交互能力和方法
资源分开报告。交互层级不进入单一总分：recipe-search 与 operation-level closed loop 只能作系统级
比较；若要归因于算法，必须处于相同交互层级并使用相同资源与信息合同。

仓库保留的 Safe-GP、SAC、旧经典矩阵和 LLM 结果均绑定升级前的后端合同，只能作为 pre-v0.5 diagnostic，
不能用于当前候选后端的算法排名。修复后的 PPO 已通过 5 个训练 seed 的 Dev 学习门禁，但正式声明仍被关闭；候选 v0.5 冻结后必须按相同信息、交互层级、实验预算、模型调用
与计算资源合同重新运行；负结果同样必须保留。

## 如何理解机理与迁移

机理干预会改变实际执行的反应网络或领域构成律，并绑定 opaque hash 和精确回放上下文。这证明环境
能产生可审计的因果变化，但不证明相同动作、测量和预算足以区分所有候选，更不证明 Agent 能识别
机理、迁移策略或在现实实验中保持排名。冻结候选版同时开放电化学 `solvent` 和
`electrolyte_profile` 反事实目标，并隐藏 evaluator provenance；因此旧证书不再绑定当前合同，完整机制
识别解释保持关闭，直到新 Gate A 在相同动作、测量和预算下重新通过。
真正的训练环境主张需要 Train→未见 Bench/Bridge 的等预算对照，并允许结果为负。

## 如何理解 LLM 记录

真实 LLM 运行必须记录模型、请求参数、token、费用、重试、失败和谱图披露条件。assigned/masked
消融保持非谱图公开证据不变。系统不请求或保存私有逐字 chain-of-thought；结构化 evidence、hypothesis、
uncertainty 和 rationale 足以进行公开审计，但不能证明模型内部机理与文字解释一致。

## 如何处理安全与第三方代码

本地学生 harness 是有界消息与进程边界，不是针对恶意代码的操作系统沙箱。运行不可信提交仍需外部
低权限、无网络、只读资源、CPU/内存/进程/墙钟受限的容器。任何真实实验决策都应由具有相应资质的
人员和机构安全流程独立审查。
